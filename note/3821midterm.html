Q1Halloween 灯笼（20 分）

题意

n 座房子 (xi, yi)，yi ∈ [−d, d] 是到路的垂直距离；灯笼只能放在路上（y = 0）。每座房子到某个灯笼的距离 ≤ d。求最少灯笼数，O(n log n)。提示：先做 yi = 0 的情况。

题型Module 2 §5 基站问题（Cell Towers）的推广 → 区间刺穿（Interval Stabbing），贪心 + 证明。

关键观察：每座房子 = 路上的一个区间

灯笼在 (p, 0)，覆盖房子 i ⇔ (p − xi)² + yi² ≤ d² ⇔ p ∈ Ii = [xi − ri, xi + ri]，其中 ri = √(d² − yi²)（|yi| = d 时区间退化为一点，仍非空）。

⇒ 问题等价于：用最少的点刺穿所有区间 I1,…,In。

算法

for each house i: L[i] = x[i] - sqrt(d^2 - y[i]^2);  R[i] = x[i] + sqrt(d^2 - y[i]^2)
sort houses by R[i] ascending                       // O(n log n)
count = 0;  last = -infinity
for each i in this order:
    if L[i] > last:            // interval i not yet stabbed
        last = R[i];  count++  // place a lantern at R[i]
return count

先做提示的 yi = 0：所有区间长 2d，就是基站问题（第一座未覆盖房子右侧 d 处放灯）。一般情形只是区间长度不同。

正确性证明（贪心，必须写）

可行性

考虑任一区间 Ii。若处理它时 Li > last，算法在 Ri ∈ Ii 放灯。否则 Li ≤ last；而 last 是某个更早处理的区间的右端点，按排序 last ≤ Ri，所以 last ∈ [Li, Ri]，已被刺穿。之后 last 只增不减，但已放的灯不会移走。故每座房子都被覆盖。

最优性（写法一：找 count 个两两不相交的区间作为下界）

设贪心放了 g1 < g2 < … < gr，第 k 盏灯由区间 Jk 触发（gk = R(Jk)）。Jk 触发时满足 L(Jk) > gk−1。因此对 j < k：R(Jj) = gj ≤ gk−1 < L(Jk)，即 J1,…,Jr 两两不相交。一个点最多刺穿其中一个，所以任何可行方案至少要 r 盏灯。贪心用 r 盏，最优。∎

最优性（写法二：stays ahead，与课件基站证明同构）

设任一可行方案的灯为 a1 ≤ a2 ≤ …。断言：ak ≤ gk（k ≤ 两者长度）。因为 J1,…,Jk 两两不相交且从左到右排列，刺穿它们的必是 k 盏不同的灯，其中刺穿 Jk 的那盏位置 ≤ R(Jk) = gk，且它至少是第 k 小的，所以 ak ≤ gk。若方案只有 r−1 盏，则所有灯 ≤ ar−1 ≤ gr−1 < L(Jr)，Jr 没被覆盖，矛盾。∎

考场推荐写法一：更短、更不容易出漏洞。

复杂度与易错点

计算区间 O(n)（假设开方 O(1)），排序 O(n log n)，扫描 O(n)。总 O(n log n)。

易错
  • 按 xi 或左端点排序（见图 1 反例）。
  • 把灯放在“第一个未覆盖房子的 xi + d”——忽略了 yi，可能根本覆盖不到这座房子本身。
  • 没写证明或只写“显然贪心最优”——按规则直接 0 分。

Q2黑盒最短路 + 闹鬼墓穴（20 分）

黑盒

ShortestPath(G, s)：输入有向无环带权图（权可正可负可零）与 s，输出 s 到每点的最短路权，O(|V|+|E|)。

(a) DAG 上非负权的最长路（5 分）

题型归约：变换输入 → 调用黑盒 → 变换输出（Module 3 §16 的“Using a reduction”）。

答案

构造 G′：同样的点和边，权 w′(e) = −w(e)。调用 ShortestPath(G′, s) 得到 d′(v)，输出 L(v) = −d′(v)（不可达时黑盒给 +∞，输出 −∞/“不可达”）。

正确性：G′ 仍是 DAG（边不变），满足黑盒前提；对任一 s→v 路径 P，w′(P) = −w(P)，所以使 w′ 最小的路径恰是使 w 最大的路径。DAG 中所有路径都是简单路径，“最长路”定义良好。

复杂度：建 G′ O(V+E)，黑盒 O(V+E)，取负 O(V)。

联系

这正是黑盒允许负权的用意。在一般图上，最长简单路是附录里的 NP-hard 问题 LongestPath——DAG 的无环性才让它变容易。（非负性在这里其实不需要。）

(b) 有环图上收集一次性边奖励（15 分）

题型Module 2 §9：强连通分量 + 凝聚图（DAG），再用 (a) 求 DAG 最长路。看到“图可能有环”+ 线性时间目标，第一反应就该是“缩 SCC”。

两个关键观察
  1. 在一个 SCC 内部可以拿到全部奖励，并且能停在 SCC 的任意一点。强连通 ⇒ 对 SCC 中每条边 (a,b)：从当前位置走到 a（存在路径），走 (a,b)；全部走完后再走到想离开的那个点。重复走的边没有奖励，但也没有损失。
  2. 离开一个 SCC 后永远回不来（否则两者应在同一 SCC）。所以一条游走经过的 SCC 序列是凝聚 DAG 上的一条路径，相邻 SCC 之间只用一条跨分量边。

算法

  1. Tarjan（或 Kosaraju）求 SCC，O(V+E)。
  2. 对每个 SCC C，R(C) = Σ{ p(e) : e 的两端都在 C 中 }（含自环），一次扫描所有边 O(E)。
  3. 构造凝聚 DAG D：每个 SCC 一个点；对每条跨分量边 e = (u,v)，加边 C(u) → C(v)，权 p(e) + R(C(v))（保留平行边或只保留最大的都可以）。O(V+E)。
  4. 只保留从 C(s) 可达的部分（或让不可达为 −∞），用 (a) 的方法求 D 中从 C(s) 出发的最长路 L(·)，L(C(s)) = 0。
  5. 输出 R(C(s)) + maxC L(C)。

技巧：把“点权” R(C) 并入进入 C 的边，使问题变成纯边权的 DAG 最长路，直接用 (a)。

正确性（proof sketch 即可）

上界（任何游走 ≤ 输出）：设游走 W 从 s 出发，依次经过 SCC C1=C(s), C2, …, Ct（由观察 2，这是 D 中的一条路径，无重复）。W 收集到的奖励来自：各 Ci 内部的边（至多 R(Ci)），以及 t−1 条转移边 e1,…,et−1（每次转移恰好一条跨分量边，且 W 不会使用其他跨分量边）。合计 ≤ R(C1) + Σi[p(ei) + R(Ci+1)] = R(C(s)) + D 中对应路径权 ≤ 输出。

下界（能达到输出）：取 D 中最优路径 C1 →e1 C2 → … → Ct，ei = (ui, vi+1)。构造游走：在 C1 中从 s 出发走遍所有内部边并停在 u1（观察 1），走 e1 到 v2，在 C2 中走遍并停在 u2……它拿到了路径上的全部奖励。∎

复杂度：每一步都是 O(|VH| + |EH|)。注意构造出来的游走可能很长，但我们只需要计算它的值。

易错
  • 直接对原图用 (a)：原图有环，黑盒前提不满足。
  • 以为是 NP-hard 的 LongestPath：本题是游走（可重复点和边），奖励只拿一次——正是 SCC 的结构让它变成多项式。
  • 把 SCC 之间的所有边奖励都加上：从 C 到 C′ 只能走一条。
  • 忘了起点所在 SCC 的奖励 R(C(s))，或忘了单点 SCC 的自环。

Q3拟阵的交（20 分）

定义

M1 ∩ M2 = (S, 𝒥1 ∩ 𝒥2)：I 独立 ⇔ I 在两个拟阵中都独立。

通用观察（三问都用得上）

交集永远满足前两条公理：∅ 在两边都独立；若 X ∈ 𝒥1∩𝒥2 且 Y ⊆ X，由各自遗传性 Y 也在两边独立。唯一可能出问题的是交换性。

(a) 给出交不是拟阵的例子（8 分）

题型拟阵公理 + 构造反例。可用清单里的拟阵（不必证明）。经典思路：二分图匹配 = 两个划分拟阵之交，而匹配不满足交换性。

答案

地集 S = {1, 2, 3}。

  • M1：划分拟阵，块 S1 = {1,2}, S2 = {3}，k1 = k2 = 1。
  • M2：划分拟阵，块 T1 = {1}, T2 = {2,3}，k1 = k2 = 1。

两者都是附录中的 PartitionMatroid。交集的独立集：∅, {1}, {2}, {3}, {1,3}（{1,2} 违反 M₁，{2,3} 违反 M₂）。

取 X = {1,3}、Y = {2}，|X| > |Y|。X∖Y = {1,3}：Y∪{1} = {1,2} ∉ 𝒥1，Y∪{3} = {2,3} ∉ 𝒥2。交换性不成立 ⇒ M1∩M2 不是拟阵。∎

易错
  • 只说“匹配不是拟阵”而不给具体 X、Y：要给出具体违反的实例。
  • 用了清单外的结构却没证明它是拟阵（题目明确要求自证）。

(b) M1 ∩ Ur 是拟阵（8 分）

证明

令 𝒥 = 𝒥1 ∩ 𝒥2 = {I ∈ 𝒥1 : |I| ≤ r}。

  1. 非空：∅ ∈ 𝒥1 且 |∅| = 0 ≤ r。
  2. 遗传：X ∈ 𝒥, Y ⊆ X ⇒ Y ∈ 𝒥1（M₁ 遗传），|Y| ≤ |X| ≤ r。
  3. 交换：X, Y ∈ 𝒥, |X| > |Y|。由 M₁ 的交换性，存在 x ∈ X∖Y 使 Y∪{x} ∈ 𝒥1。又 |Y∪{x}| = |Y| + 1 ≤ |X| ≤ r，所以 Y∪{x} ∈ 𝒥2。故 Y∪{x} ∈ 𝒥。∎

关键一行：|Y| < |X| 推出 |Y| + 1 ≤ |X|（整数）。这叫拟阵的“截断（truncation）”。对比 (a)：一般交集失败，是因为 M₁ 给出的 x 未必被 M₂ 接受；而均匀拟阵只看大小，x 自动被接受。

(c) 给孩子分糖（4 分）

题型识别拟阵 + 加权拟阵贪心（Module 2 §11）。

答案

建模：地集 = n 个孩子。约束“每区 Dj 至多 dj 个”是划分拟阵 M1（块 D1,…,Dm，上限 dj；每个孩子恰属一个区 ⇒ 确实是划分）；“总数至多 k”是均匀拟阵 Uk。可行集族 = 𝒥(M1) ∩ 𝒥(Uk)，由 (b) 是拟阵 M（k = 0 时答案为空集）。

算法：按 wi 降序排序；维护每区计数 cnt[j] 与总数 tot；依次考虑孩子 i（区 j）：若 cnt[j] < dj 且 tot < k 则选入并更新计数。

正确性：这正是课上的加权拟阵贪心，独立性测试为“加入后仍满足两个计数约束”。贪心返回最大权基；由于 wi ≥ 0，任何独立集都可扩充为基且权重不减，所以最大权基就是所有可行集合中权重最大的。

复杂度：排序 O(n log n)；每次独立性测试 O(1)，共 n 次 ⇒ O(n log n + n·1) = O(n log n)（定理中的 O(n log n + n f(n))，f = O(1)）。

易错

题目是 4 分，但“贪心要证明”仍适用——引用“M 是拟阵（由 b + 清单）+ 拟阵贪心定理”就是证明，一定要写出这两句，以及“权重非负 ⇒ 最大权基最优”。

Q4最小权“几乎是树”子图（20 分）

题意

连通图 G、非负边权。almost-a-tree：连通、生成（含所有点）、恰好一个环。求最小权，O(|E| log |V|)。

题型MST（Kruskal + 并查集）+ 交换论证。

关键观察
  • 连通生成子图恰有一个环 ⇔ 它有 |V| 条边 ⇔ 它 = 某棵生成树 + 一条额外边。（删掉环上任意一条边就得到生成树。）
  • 答案 = MST 权 + 最轻的非 MST 边。在 Kruskal 中，最轻的非树边就是第一条被拒绝的边。
算法
  1. 若 |E| < |V|（G 本身是树），不存在 almost-a-tree，报告无解。
  2. 运行 Kruskal（并查集 + size 启发式）处理完所有边，得到 MST T，记录第一条被拒绝的边 emin（等价于：建完 T 后扫描所有非树边取最小）。
  3. 输出 w(T) + w(emin)（子图为 T ∪ {emin}）。
正确性（交换论证，应写完整）

可行：T 是生成树，加入非树边 emin 恰好产生一个环（基本环），仍连通、生成 ⇒ 是 almost-a-tree。

最优：任取 almost-a-tree H，记其唯一的环为 C。因为 T 无环，C 不可能全在 T 中 ⇒ C 上存在边 g ∉ T。删去 g：H − g 仍连通（g 在环上），有 |V|−1 条边 ⇒ 是生成树，故 w(H − g) ≥ w(T)。又 g ∉ T ⇒ w(g) ≥ w(emin)。于是

w(H) = w(H − g) + w(g) ≥ w(T) + w(emin)。∎

为什么第一条被拒绝的边是最轻的非树边：Kruskal 按升序处理所有边，非树边恰好就是被拒绝的边。

复杂度：排序 O(E log E) = O(E log V)；2E 次 Find、V−1 次 Union，各 O(log V) ⇒ O(E log V)。

易错
  • “加全图最轻的边”：它往往已经在 MST 里了，必须是非树边。
  • 证明里直接断言“最优解一定包含 MST”——不对（最优解不一定含某棵特定 MST，例如权重相同时），要用上面“环上必有非树边 g”的交换。
  • Kruskal 在凑够 n−1 条边后提前停止，就拿不到被拒绝的边——要么继续扫，要么事后扫一遍非树边。

Q5Haunting Set（20 分）

定义

有向图中 u haunts v ⇔ u = v 或 (u,v) ∈ E。Haunting set H：每个点都被 H 中某点 haunt（即有向图的支配集：H ∪ N⁺(H) = V）。

(a) DAG 上的 Haunting Set 是 NP-hard（10 分）

题型Module 3 NP-hardness 归约，指定从 Set Cover 出发。

设计思路

Set Cover：“选 ≤ k 个集合，盖住所有元素”。Haunting：“选 ≤ k′ 个点，haunt 所有点”。自然的对应：集合 ↦ 点，元素 ↦ 点，集合 → 它包含的元素。这样选中的集合点会 haunt 它的元素。

问题：集合点入度为 0，没人能 haunt 它们，只能自己进 H ⇒ 所有 m 个集合点都必须选，规模失控。补丁：加一个超级根 r，r → 每个集合点。r 入度 0 必选，但它一个就 haunt 了全部集合点。预算设为 k + 1。

完整答案（可直接照写）

归约：给定 Set Cover 实例：全集 U = {u1,…,un}，子集 S1,…,Sm（并为 U），整数 k。构造有向图 G：

  • 点：根 r；每个集合一个点 sj；每个元素一个点 ei。
  • 边：r → sj（所有 j）；sj → ei ⇔ ui ∈ Sj。
  • 参数：k′ = k + 1。

G 是 DAG（所有边从第 0 层到第 1 层或第 1 层到第 2 层）。点数 1+m+n，边数 m + Σ|Sj|，多项式时间构造。

(⇒) 若存在大小 ≤ k 的覆盖 𝒞，令 H = {r} ∪ {sj : Sj ∈ 𝒞}，|H| ≤ k+1。r haunts 自己和所有 sj；每个 ei：ui 属于某个 Sj ∈ 𝒞，于是 sj ∈ H haunts ei。H 是 haunting set。

(⇐) 设 H 是大小 ≤ k+1 的 haunting set。

  1. r 入度为 0，只有 r 自己能 haunt r ⇒ r ∈ H。
  2. 规范化：若某个元素点 ei ∈ H，它出度为 0，只 haunt 自己；把它换成任意一个包含 ui 的集合点 sj（存在，因为各集合的并为 U）。sj 同样 haunt ei，H 仍是 haunting set，大小不增。
  3. 现在 H = {r} ∪ {sj : j ∈ J}，|J| ≤ k。每个 ei 不在 H 中、又不能被 r haunt，只能被某个 sj, j ∈ J haunt ⇒ ui ∈ Sj。故 {Sj : j ∈ J} 是大小 ≤ k 的覆盖。

因此 Set Cover ≤P Haunting Set on DAGs，后者 NP-hard。∎

关于“恰好 k 个”与“至多 k 个”：清单里 SetCover 写的是“k 个子集”。若有 ≤ k 个的覆盖，补任意集合就有恰好 min(k, m) 个；k ≥ m 时实例平凡为 YES。写一句说明即可。（题目只要求 NP-hard；若要 NP-complete，再补一句“H 本身就是可在线性时间验证的证书”。）

易错
  • 漏了根 r（或把预算设成 k）：集合点无人 haunt，归约直接错误。
  • (⇐) 方向没处理“H 里可能有元素点”——需要规范化（替换）这一步。
  • 方向反了：把 Haunting Set 归约到 Set Cover 证明不了难度。
  • 构造的图有环（例如元素指回集合），题目要求 DAG。

(b) 竞赛图上 Greedy-THS 输出 O(log n) 大小的 haunting set（4 分）

证明

输出是 haunting set：每轮至少删除被选点 v 本身，算法终止。每个被删除的点 u 都被当轮选中的 v haunt（u = v 或 (v,u) ∈ E，剩余图是原图的诱导子图，边就是原图的边）。所有点最终都被删 ⇒ 每个点都被 H 中某点 haunt。

规模：剩余图始终是竞赛图（竞赛图的诱导子图仍是竞赛图）。设当前剩 n′ 个点：每对点恰贡献一条边，出度之和 = C(n′,2) = n′(n′−1)/2，所以最大出度 ≥ (n′−1)/2。选中 v 后删除 v 及其出邻居，至少 1 + (n′−1)/2 = (n′+1)/2 个点，剩下至多 (n′−1)/2 < n′/2。每轮剩余点数至少减半，t 轮后 < n/2t，所以至多 ⌊log₂ n⌋ + 1 轮 ⇒ |H| = O(log n)。∎

与 Module 3 的关系：这是 Set Cover 型贪心的“每步至少覆盖一个常数比例”分析；也顺带说明竞赛图的最小 haunting set 总是 O(log n)。

(c) Greedy-THS 是否总是最优？——否（6 分）

题型贪心反例构造。“Prove or disprove” 题，几乎都是要你构造反例；最好让贪心的选择唯一，避免“平局时选得好就对了”的争议。

反例思路

让出度最大的点 v 是最优解的一部分，但它的“搭档” u 正好是 v 的出邻居——贪心选 v 后就把 u 删掉了（被 haunt 的点从图中移除，不能再作为 haunter），剩下的部分又是一个需要 2 个点的 3-环。

验证（写在答卷上）

是竞赛图：W 内部的旋转构造对每对 wi, wj 恰给一个方向（差为 1,2,3 时 i→j，差为 4,5,6 时 j→i）；v 与 W、W 与 R、R 与 v、R 内部每对恰一条边。

最优 ≤ 2：H* = {v, w0}：v haunts v 和全部 W；w0 haunts 全部 R。（且没有点出度为 10，所以最优恰为 2。）

贪心 = 3：v 的出度 7 是唯一最大值，贪心必选 v，删去 v 与 W，剩下 R（3-环）。在 3-环中每点出度 1，无论选谁，只删掉 2 个点，还剩 1 个，需再选它。贪心输出 3 个点 > 2。∎

贪心错在：w₀ 本来是 v 的最佳搭档（它能一口气 haunt 整个 R），但它被 v haunt 后从图中删除了，后面没机会再被选作 haunter。

L1附录：NP-hard 问题清单逐条讲解

附录给了两版清单：第一版（期中卷里）多用优化说法（“最大/最小是多少”），第二版用判定说法（“是否存在大小为 k 的……”）。做 Karp 归约时用判定版：输入里多一个参数 k，答案是 YES/NO。优化版本身是 NP-hard（但不在 NP 中，因为输出不是 YES/NO）。

“该从哪个问题归约？”速查
目标问题的样子首选起点理由
选少量东西“覆盖/支配/触及”所有东西SetCover、VertexCover、HittingSet覆盖结构一一对应（Q5a 就是）
选很多东西，两两“不冲突/都兼容”IndSet、Clique冲突 = 边
把对象分到少量组，组内不能冲突3Col、ChromaticNumber组 = 颜色
排一个顺序 / 走一条经过所有点的路HamPath、HamCycle、TSP、LongestPath顺序 = 路径
数字、重量、时间凑成某个和 / 平均分SubsetSum、Partition、3Partition数值和约束
一般的逻辑约束、需要设计小件3Sat最灵活：变量小件 + 子句小件
连通少量指定点的最小结构SteinerTree（或从 SetCover 构造）连通性

逻辑类

Sat

问：一个 CNF 公式（若干子句的 AND，每个子句是文字的 OR）是否有满足赋值？
例：(x∨¬y) ∧ (y∨z) ∧ (¬x∨¬z)：x=1, y=1, z=0 满足。
地位：Cook 定理的第一个 NP-complete 问题。

3Sat

问：每个子句恰有 3 个不同文字的 CNF 是否可满足？
为何常用：结构整齐，适合“变量小件 + 子句小件 + 连接”的归约（课上的 VC、Clique、3Col 都从它出发）。
注意：2Sat ∈ P，不能用作起点。

图类：选点 / 选边

VertexCover（点覆盖）

问：是否有 k 个点，使每条边至少一个端点被选？
例：星形图中心一个点即可覆盖所有边。
关系：S 是点覆盖 ⇔ V∖S 是独立集。VC ≤ SetCover：元素 = 边，每个点对应“与它相连的边”的集合。
用于：任何“每个约束对（边）至少选一个”的问题。

IndSet（独立集）

问：是否有 k 个点两两不相邻？
例：5-环的最大独立集为 2。
关系：G 的独立集 = 补图 Ḡ 的团；大小 k 的独立集 ⇔ 大小 n−k 的点覆盖。
用于：调度/选择中“冲突对不能同时选”的问题（区间图上是活动选择，多项式！一般图上难）。

Clique（团）

问：是否有 k 个点两两相邻（完全子图）？
例：三角形是 3-团。
关系：3Sat ≤ Clique（k = 子句数）；VC ≤ Clique（补图，n−k）。
用于：“选出的东西必须两两兼容”。

3Col 与 ChromaticNumber（着色）

3Col 问：能否用 3 种颜色给点着色使相邻点不同色？
ChromaticNumber：最少需要几种颜色（判定版：能否用 k 色）。3Col 是它在 k=3 的特例 ⇒ 后者也难。
例：奇数环需要 3 色；完全图 K₄ 需要 4 色。
注意：2 色（二分图判定）∈ P；区间图/完美图上着色多项式。
用于：把东西分成若干组/时段/频道且冲突的不能同组（考试排时间表、寄存器分配）。

集合类：覆盖与击中

SetCover（集合覆盖）

问：给全集 S 和子集 S1,…,Sm（并为 S），能否选 k 个子集使并为 S？
例：S={1..5}，子集 {1,2,3},{2,4},{3,4,5},{1,5}，k=2 时 {1,2,3}+{3,4,5} 可行。
用于：Q5(a)；任何“选 k 个工具/站点/传感器盖住所有需求”的问题。归约时通常把“集合”和“元素”各变成一种对象，“包含”变成某种关系（边、覆盖、可达）。
相关：贪心（每次选覆盖最多新元素的集合）是 ln n 级近似——Q5(b) 的分析就是这个味道。

HittingSet（击中集）

问：能否选 S 中 k 个元素，使每个子集 Si 都至少含一个被选元素？
关系：它是 SetCover 的“转置”：把元素与集合的角色互换（元素 x 变成集合 {i : x ∈ Si}）。VertexCover 是每个集合大小为 2 的击中集（集合 = 边）。
用于：“每个约束组里至少选一个”（如每门课至少一个助教会的时间）。

路径与巡回类

HamCycle / HamPath（哈密顿回路 / 路径）

问：（有向或无向）图中是否有经过每个点恰好一次的回路 / 路径？
对比：每条边恰好一次（Euler）∈ P。
用于：排序、排列、“访问每个对象一次”的问题。

LongestPath（最长简单路）

问：是否存在长度为 k 的简单路径？（可带权）
关系：HamPath ≤ LongestPath（k = n−1）。
对比：最短路 ∈ P；DAG 上最长路 ∈ P（Q2a，取负 + 拓扑序）。
易错：别把 DAG/可重复走的版本误判为 NP-hard（Q2b 就是陷阱）。

TravellingSalesperson（旅行商）

问：正整数边权图中，是否有总权 ≤ k 的哈密顿回路（或路径）？
关系：HamCycle ≤ TSP（原边权 1，非边权 2 或很大，k = n）。
近似：满足三角不等式时 2-近似（MST 绕行）；一般情形无常数近似（除非 P=NP）。

SteinerTree（斯坦纳树）

问：给图 G、终端点集 S，是否有至多 k 条边的子树连通 S 中所有点？（可以经过非终端点）
对比：S = V 时就是生成树（∈ P）；|S| = 2 时就是最短路（∈ P）。
常见归约（SetCover ≤ SteinerTree）：根 r 连到每个集合点，集合点连到所含元素点，终端 = {r} ∪ 元素；有 ≤ k 个集合的覆盖 ⇔ 有 ≤ k + n 条边的 Steiner 树。（与 Q5a 的三层结构几乎一样！）

数值类

SubsetSum（子集和）

问：正整数集合 X 是否有子集和恰为 t？
例：X={3,5,6,8}，t=14：3+5+6 = 14 ✓；t=12 则无解。
注意：DP O(n·t) 只是伪多项式（t 用 log t 位表示）。精确指数算法：meet in the middle O(n 2n/2)。

Partition（划分）

问：能否把正整数集合分成和相等的两部分？
关系：Partition ≤ SubsetSum（t = 总和/2，总和为奇数时直接 NO）；反方向也成立（加一两个辅助数）。
用于：两台机器负载平衡、两人平分财产等。

3Partition（三元划分）

问：3n 个正整数能否分成 n 个三元组，每组和相同？
特点：强 NP-hard——即使数字用一进制写（数值很小）也难，所以不能靠伪多项式 DP 绕开。
用于：多机调度、装箱（bin packing）、拼图类问题，尤其是目标问题里的数值本身不大时。

清单里几对“互相归约”的速记
  • IndSet ↔ VertexCover：取补集，k ↔ n−k。
  • IndSet ↔ Clique：取补图，k 不变。
  • SetCover ↔ HittingSet：元素与集合互换。
  • 3Col → ChromaticNumber：令 k=3。
  • HamPath → LongestPath：k=n−1；HamCycle → TSP：权 1/2，k=n。
  • Partition → SubsetSum：t = Σ/2。
  • 一般化原则：目标问题包含清单问题作为特例 ⇒ 直接“嵌入”即证 NP-hard（如 Weighted Set Cover ⊇ Set Cover）。

L2附录：拟阵清单逐条讲解

考试可直接引用这四个拟阵，不必证明。最常见的用法：①把题目里的约束识别成它们（或它们的组合），然后套拟阵贪心；②用它们构造“不是拟阵”的反例（Q3a）。

CycleMatroid（环拟阵 / 图拟阵）

定义：G=(V,E)，地集为边 E，独立 ⇔ 边集无环（构成森林）。基：生成森林（G 连通时为生成树）。

例：三角形 abc：任意 ≤ 2 条边独立，3 条边成环不独立；基 = 任意两条边。

用途：最小/最大生成树（Kruskal = 拟阵贪心）；Q4。交换性直觉：边更多的森林连通分量更少，必有一条边跨越另一森林的两个分量。

MatchingMatroid（匹配拟阵）

定义：地集为顶点 V，V′ 独立 ⇔ 存在一个匹配覆盖 V′ 中所有点。基：最大匹配所覆盖的顶点集。

例：路径 a–b–c：{a,b} 独立（匹配 ab），{a,c} 独立吗？需要一个匹配同时覆盖 a 和 c：ab 与 bc 共享 b，不行 ⇒ 不独立。{b} 独立。

⚠ 易混：边的匹配集合本身不构成拟阵（Q3a 图 3 就是反例：极大匹配大小不同）。匹配拟阵的元素是“被覆盖的顶点”，不是边。

用途：顶点有权重，想让被匹配的顶点总权最大 ⇒ 按顶点权贪心（每步检查是否还存在覆盖它们的匹配）。

PartitionMatroid（划分拟阵）

定义：地集 S 划分为 S1,…,Sℓ，独立 ⇔ |S′ ∩ Si| ≤ ki 对每块成立。

例：学生按年级分块，每年级最多选 2 人做代表。

用途：“每类最多若干个”的配额约束（Q3c 的区限额）。交换性证明：|X| > |Y| ⇒ 必有某块 i 满足 |X∩Si| > |Y∩Si|，取 x ∈ (X∖Y)∩Si，加入后 |Y∩Si|+1 ≤ |X∩Si| ≤ ki。

注意：块必须不相交。若一个元素同时属于多个组（如一个孩子属于两个区），就不再是划分拟阵，交集可能不是拟阵（Q3a 正是两种不同划分的交）。

UniformMatroid（均匀拟阵 Uk）

定义：独立 ⇔ |S′| ≤ k。基：大小恰为 k 的集合。

例：从 n 件物品中至多拿 k 件，最大化总价值 ⇒ 取最贵的 k 件（贪心）。

用途：“总数至多 k 个”。它是只有一块的划分拟阵。由 Q3b：任何拟阵 ∩ 均匀拟阵仍是拟阵（截断），所以“原约束 + 总数上限”总能直接用贪心。

拟阵相关题型的判断流程
  1. 题目问“选一个集合，满足某些上限型约束，最大化非负权和”？→ 怀疑是拟阵。
  2. 能否写成清单里的拟阵，或 “某拟阵 ∩ 均匀拟阵”？能 → 引用 + 贪心 + 排序复杂度。
  3. 是两个不同划分的交（如二分图匹配、带两种配额）？→ 一般不是拟阵，贪心可能错（要么找反例，要么用其他算法如网络流）。
  4. 自定义结构 → 逐条验证三公理；证否则给具体 X、Y。

L3考场写作模板汇总

NP-hard 证明（以 Q5a 为样板）
  1. “We reduce from X (NP-hard by the list).” 写出 X 的输入。
  2. 构造：点、边/元素、参数（k′ = …），说明满足目标问题的特殊要求（如 DAG、竞赛图、平面……）。
  3. 构造是多项式规模、多项式时间。
  4. (⇒) 由 X 的解构造目标解。
  5. (⇐) 由目标问题的任意解，先规范化（WLOG 不含某类点/换成某类点），再读出 X 的解。
  6. 结论。（如要 NP-complete，加上“在 NP 中”。）
贪心算法题（以 Q1 / Q4 为样板）
  1. 转化：把原问题变成熟悉的模型（区间、MST、拟阵）。
  2. 算法：排序准则 + 扫描时维护的状态。
  3. 可行性：输出满足约束。
  4. 最优性：stays ahead / exchange / 下界构造（不相交区间、环上的非树边）/ 拟阵定理。
  5. 复杂度：排序 + 每步代价。
  6. （自检）找一个反例试试“看似合理”的其他排序准则，确认自己没选错。
“Prove or disprove” 题（以 Q5c 为样板）
  1. 先在小例子上手算，判断方向（这类题多半是 disprove）。
  2. 构造反例时让算法的每一步选择唯一（避免平局争议）。
  3. 分别给出：算法的输出（数值）、更好的解（显式写出）、为什么算法的选择是被迫的。
本卷最容易丢分的地方

  • Q2b 没想到 SCC，或者把跨分量的所有边奖励都加上。
  • Q3a 给出的例子不在清单中又没证明它是拟阵；只说“匹配不是拟阵”没有具体 X、Y。
  • Q3c 忘了说明为什么约束构成拟阵（应引用 b）。
  • Q4 加的是全局最轻边而不是最轻非树边；证明里假设“最优解包含 MST”。
  • Q5a 没有根 r，或只证一个方向，或 (⇐) 方向没处理元素点在 H 中。
  • Q5c 反例中贪心有平局，或者没说明最优确实更小。
