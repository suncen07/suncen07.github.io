01 / UNDERSTAND THE QUESTION

题目到底要证明什么？

原题：A graph G is triangle-free if it contains no three pairwise-adjacent vertices. Given a triangle-free graph G = (V, E) and a nonnegative integer k, prove that it is NP-hard to decide whether G has an independent set of size at least k.

Independent set（独立集）：顶点集合 I ⊆ V，其中任意两点之间都没有边。问题问是否存在 |I| ≥ k。

Triangle-free（无三角形）：图中不存在三个彼此都有边相连的顶点。它不是说“没有环”，更不是说“没有边”！它仍然允许 4、5、6、9 等长度的环。

真正的目标：已知一般图上的 Independent Set 是 NP-hard。我们要证明：即使规定输入图不能包含任何三角形，问题仍然难。

因此，不能仅仅说“Independent Set 已经 NP-hard，所以这个版本也是”。因为 限制输入范围后，问题可能变简单；必须真正构造一个归约。

02 / FIND THE REDUCTION

最关键的想法：把原图中的每条边「拉长」

从已知 NP-hard 的一般 Independent Set 归约：
把每条原边 {u, v} 替换成长度为 3 的路径 u — ae — be — v。

为什么恰好要加入两个点？

  1. 消除三角形。原图里相连的两个旧顶点现在不再直接相连。每个新顶点只与路径上的两个邻居相连，而且这两个邻居之间没有边，所以不会形成三角形。
  2. 给每条旧边提供最多 1 个可选的新顶点。因为 ae 和 be 相邻，所以两者最多选一个。
  3. 保留旧边带来的冲突。如果我们同时选了旧边的两个端点 u 和 v，中间两个新点都不能选；这条边就会少贡献 1 个顶点。冲突没有消失，而是变成了可以计数的“损失”。

一句话核心：用一个局部 gadget，把原来的“两个端点不可以同时选”转化为“如果两个端点同时选，那么这条边就损失一个新顶点”。

设 m = |E|。每条原边对应一份这样的 gadget，所以新图中的最优独立集大小将恰好是 m 加上原图的最优独立集大小：

α(G′) = α(G) + m

我们不能只把这个关系当成直觉；接下来会通过两方向证明它。

03 / INTERACTIVE LOCAL GADGET

亲手看一次：选与不选，为什么刚好损失 1？

先只看旧边 e = {u,v} 对应的 4 个点。点击不同情况。绿色表示当前选入独立集的顶点。图中中间顶点按“能选多少就选多少”的原则自动选择。

表格揭示了阈值为什么是 k + m：如果旧顶点构成独立集，每条原边都不会出现两端同时被选的情况，于是每条原边都能额外贡献 1 个点；总共 m 条边，便增加 m 个点。

为什么不只插入一个点 u—a—v？插入一个点会把整张图变成二分图（旧顶点在一边，新顶点在另一边），而二分图的最大独立集可在多项式时间求出。因此这种构造无法给出所需的 NP-hard 归约（除非 P=NP）。更重要的是，它没有上述“每条边贡献 1、双端冲突少 1”的统一计数规律。

04 / PROVE IF AND ONLY IF

双向证明：真正容易卡住的是反方向

先把变换和目标值写清楚

输入：任意 Independent Set 实例 (G=(V,E), k)。记 m=|E|。

输出：把所有边 {u,v} 替换成 u—ae—be—v 得到 G′，并设 k′=k+m。

G 有大小 ≥ k 的独立集
⇔
G′ 有大小 ≥ k + m 的独立集

方向一（⇒）：原图 YES → 新图 YES

已知原图有独立集 I，其中 |I| ≥ k。

因为 I 独立，所以对每条旧边，最多一个端点落在 I。按交互表，每条边都可额外选 1 个内部顶点。

不同 gadget 的内部顶点之间互不相邻。总共得到：

|I′| = |I| + m ≥ k + m

这一方向通常比较直观：直接构造一个新图里的独立集即可。

方向二（⇐）：新图 YES → 原图 YES

已知新图有独立集 J，其中 |J| ≥ k+m。

令 S=J∩V（只取原图中的旧顶点）。S 未必在原图里独立！因为原来的边被删除了。

设 t=|E(G[S])| 是 S 内部原本存在的边数。每条这样被“双端选中”的旧边对应 0 个可选内部点，其余 m-t 条边最多各提供 1 个：

|J| ≤ |S| + m − t

因此 |S| − t ≥ k。针对 S 中的每条冲突边，删去其中一个端点；最多删除 t 个旧顶点，就能消除所有旧边。

留下的 T 是原图的独立集，且 |T|≥|S|−t≥k。

反方向的关键不是直接说“保留旧顶点即可”。旧顶点中可能仍有原图的边；必须用 t 统计这些冲突，再利用 k+m 的下界保证：即使修复冲突，旧顶点仍然至少保留 k 个。

为什么“删除至多 t 个顶点”一定成立？对 G[S] 中的每一条边，指定一个端点准备删除；把被指定的所有顶点的并集删除。至多指定 t 个不同顶点，且每一条边至少失去一个端点，因此剩余集合没有任何边。

05 / WORKED EXAMPLE

拿最简单的三角形试一下：K₃ → C₉

假设原图本身是一个三角形 K₃，三个顶点 A,B,C。原图的最大独立集只能选 1 个点，即 α(G)=1。

对这个例子，m=3，因而 α(G′)=1+3=4。比如输入原图的 k=2（答案 NO），转换后要求 k′=5，而新图的最大独立集只有 4，答案仍是 NO。若 k=1，两边都是 YES。

这个例子只能帮助验证直觉，不能替代上一节对任意图的两个方向的证明。

06 / EXAM-READY FORMAL PROOF

Formal English proof（按照 sample solution 的结构）

下面是可以直接参考的英文正式证明：先描述归约，再说明合法性和两方向，最后分析时间并得出 NP-hard。

Solution.

We reduce from Independent Set, which is NP-hard. Given an instance (G=(V,E),k), let m=|E|. For every edge e={u,v}∈E, delete e, introduce two new vertices ae and be, and add the three edges {u,ae}, {ae,be}, and {be,v}. Let the resulting graph be G′, and set k′=k+m.

Observe that G′ is triangle-free: every new vertex has two neighbours that are not adjacent to each other, and no two original vertices are adjacent in G′.

We claim that G has an independent set of size at least k if and only if G′ has an independent set of size at least k+m.

  • (⇒) Suppose that G has an independent set I of size at least k. For every original edge e={u,v}, at most one of u and v belongs to I. Hence, we can choose one of ae and be that is not adjacent to any vertex of I. Since vertices introduced for different edges have no edges between them, these choices together with I form an independent set in G′ of size |I|+m≥k+m.
  • (⇐) Suppose that G′ has an independent set J of size at least k+m. Let S=J∩V, and let t be the number of edges of G with both endpoints in S. For each such edge e={u,v}, neither ae nor be can belong to J. For each of the remaining m−t edges, at most one of its two new vertices can belong to J, since they are adjacent. Therefore,
    k+m ≤ |J| ≤ |S|+(m−t),
    so |S|−t≥k. By deleting at most one endpoint of each of the t edges induced by S in G, we obtain an independent set I in G with |I|≥|S|−t≥k.

The construction introduces exactly 2m new vertices and replaces each original edge with three edges. It therefore runs in polynomial time. Thus, Independent Set on triangle-free graphs is NP-hard. ∎

英文证明结构与 sample 一致：“We reduce from ...” → “We claim ... if and only if ...” → “(⇒)” → “(⇐)” → “The reduction runs in polynomial time. Thus ... is NP-hard.”

07 / WHAT CAN GO WRONG

考试最容易失分的地方

01
只删除三角形中的边，不设计对应关系。
删除边可能让原图的最大独立集变大，却无法用固定阈值恢复原问题。归约必须保持 YES / NO 等价。
02
把目标设成 k，而不是 k+|E|。
新增顶点确实能进入独立集；不对它们的贡献做补偿，答案就可能改变。每条原边有一个“正常贡献”，因此整体补偿 m。
03
反方向错误地认为 J∩V 自动是原图独立集。
它在 G′ 中确实没有旧顶点之间的边，但这些边在 G 中原本存在。一定要统计原图诱导子图中的冲突边 t，然后删除至多 t 个端点。
04
只说明新图 triangle-free，没有完成 if and only if。
证明归约的输出满足限制只是第一步。还必须分别证明原实例 YES ⇒ 新实例 YES，以及新实例 YES ⇒ 原实例 YES。
05
把 NP-hard 与 NP-complete 混为一谈。
本题要求 NP-hard。上面的归约足够。如果要额外证明 NP-complete，只须再说明给定顶点集合可在多项式时间检查其大小及独立性，即问题属于 NP。
08 / ONE-MINUTE RECAP

最后复习时，只需要抓住这条主线

  1. 从一般图的 Independent Set 归约。
  2. 将每条旧边 u—v 替换为 u—a—b—v，保证新图 triangle-free。
  3. 每条原边正常提供 1 个内部顶点；如果两端都选，则该边贡献 0。
  4. 目标改为 k′=k+|E|。
  5. 正方向，每条边补 1 个新点；反方向，用 t 个冲突边的损失保证删掉冲突后还有至少 k 个旧顶点。
  6. 构造只需 O(|V|+|E|) 时间，因此得到 NP-hard。
α(G′) = α(G) + |E|

这就是整道题的核心不变量：删掉了旧边的直接邻接关系，但通过内部点的“损失”，保留了原来的选择冲突。
