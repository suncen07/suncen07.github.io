01 · Transformer 的动机与三种结构

对应课件第 3–6 页

1. 为什么不一直用 RNN / LSTM？

RNN 的基本形式是 h_t = f(h_{t−1}, x_t)：计算第 t 个状态前，必须先得到第 t−1 个状态，因此长度为 n 的句子在时间方向上至少有 n 个依赖步骤。LSTM 的门能够缓解梯度消失，但仍沿时间依次更新。

考虑课件例句 “The dogs that the cat chased were …”。要判断用 were 还是 was，模型需要把较早出现的复数主语 dogs 和后面空缺相连。RNN 需要通过很多次状态传递，而 Self-Attention 可以在一层内直接建立远距离位置之间的关系。

Transformer 的关键变化：不靠时序递推传信息，而让所有位置各自提出一个 Query，查询其他位置的 Key，然后对相应的 Value 加权求和。 这样训练时同层不同 Token 可以并行。

2. 三种 Transformer 的差别一定要分清

Encoder-only（例如 BERT）：所有输入 Token 彼此可见，没有因果遮挡。模型输出每个位置的上下文化表示；分类时读 [CLS]，序列标注时读每个 Token，抽取式问答时预测答案起止位置。

Decoder-only（例如 GPT）：第 i 个 Token 只能看位置 0…i。模型用这些前缀信息预测位置 i+1 的 Token。训练时可以对已知文本的全部位置同时计算 Loss；生成时不能一次知道未来，只能逐步追加。

Encoder–Decoder（例如原始 Transformer/T5）：Encoder 读完整输入，Decoder 读取已经生成的目标前缀，且 Decoder 通过 Cross-Attention 查 Encoder 的输出。这种结构适合输入和输出不是同一序列的任务。

4. Transformer 的代价

标准密集 Self-Attention 需要 n × n 对 Query–Key 打分，形成每 Head 的 n × n 权重矩阵；一个层的核心注意力乘法大致为 O(n² d_model)（简化的课堂比较，不含全部投影与 FFN 项）。这在短文本可接受，但当 n 翻 10 倍，配对数量约翻 100 倍，这也是后面 Sparse / Flash / Linear / Mamba 等方法出现的原因。

02 · BERT：完整 Encoder 从输入到输出

对应课件第 8–47 页；本课篇幅最大、公式最密集的核心部分

1. BERT 究竟学到了什么？

BERT 是 Bidirectional Encoder Representations from Transformers。同一个 Token 的向量会受整句话上下文影响，例如 it 可通过 Attention 聚合 animal 的信息；这和只有固定 Embedding 词表向量的表示不同。

课件的玩具例句：[CLS] the animal didn't cross the street because it was too tired [SEP]。原讲义用 n=13、d_model=4、h=2、每 Head d_k=2、d_v=3 的小模型，把每一步的数值列出来。下文沿着它的处理顺序讲解。

2. Tokenisation 与输入 Embedding

Step 1：Token → ID → 向量。 Token 可以是完整单词，也可能是子词。BERT 特殊 Token 常见有 [CLS]（起始，常用于整句任务）、[SEP]（分隔）、[MASK]（预训练遮挡）。每个 ID 从学习到的 Embedding 表 E ∈ ℝ^{|Vocab| × d_model} 中选一行。

Step 2：加入位置信息和 Segment 信息。 BERT 的原版输入可以写成：

xᵢ = E[tokenᵢ] + P[i] + S[segmentᵢ]
  • E[tokenᵢ] 告诉模型这是什么 Token；P[i] 告诉模型在第几个位置；S[A/B] 告诉模型属于两段输入中的哪一段。
  • 相同的 the 在两个位置的 E 相同，但 P 不同，所以最终输入不同。
  • 原版 BERT 用可训练的绝对位置向量表；原始 2017 Transformer 则使用固定正弦/余弦编码，不能混淆。
  • 课件玩具算例 it 的三组向量：E=[−0.2,−1.7,−1.5,2.2]、S=[0.1,−0.1,0,0.1]、P=[−0.4,0.4,−0.1,−0.3]，相加得到 [−0.5,−1.4,−1.6,2.0]（第 15 页）。

为什么 Attention 需要位置编码？ 不编码位置信息时，注意力本身对输入的排列不敏感（严格说是排列等变）；它只处理 Token 内容间的配对，无法仅靠注意力区分 dog bites man 与 man bites dog 的语序。

Step 2b：Layer Normalisation。 对每一个 Token 的 d_model 维向量，计算均值 μ 和标准差 σ，按维度标准化后再用学习到的 γ、β 调整。

LayerNorm(x) = γ ⊙ (x − μ) / √(Var(x)+ε) + β

在课件的数字示范中先使用简化的 (x−μ)/σ。例如 it 的输入归一化约为 [−0.08,−0.71,−0.85,1.66]（第 16 页）。注意 LayerNorm 沿一个 Token 的特征维度计算，而非跨 Batch 或全句位置。

3. Self-Attention 的核心：Q、K、V 在做什么？

把归一化后的输入堆成矩阵 X ∈ ℝ^{n×d_model}。每个 Attention Head 有三套可学习的投影：

Q = XW_Q,　K = XW_K,　V = XW_V
  • Query（Q）：当前 Token 希望寻找什么信息。
  • Key（K）：当前 Token 提供什么“检索索引”，以便与别人的 Query 匹配。
  • Value（V）：当被注意到时，真正传给查询者的内容。

以 it 找 animal 为例：it 的 Query 与 animal 的 Key 匹配度很高，于是 it 的输出会得到较大比例的 animal 的 Value。注意：相似度由 Q·K 决定，被混合的是 V，而不是 K。

4. 一次 Attention 如何算出来？（考试必练）

Step 3：矩阵维度。 对课件玩具单 Head：X(13×4) 乘 W_Q(4×2) 得 Q(13×2)；同理 K(13×2)；X(13×4) 乘 W_V(4×3) 得 V(13×3)。

Step 4：Query 与所有 Key 做点积，并除以 √dₖ。

S = QKᵀ / √dₖ，　sᵢⱼ = qᵢ · kⱼ / √dₖ

S 是 13×13；第 i 行是位置 i 在问，第 j 列是被问的 Token。课件中 q_it=[−1.05,1.18]、k_animal=[−1.73,1.66]，因此：

q_it · k_animal = (−1.05)(−1.73) + (1.18)(1.66) ≈ 3.78
s_it,animal = 3.78 / √2 ≈ 2.67

为什么要除以 √dₖ？ 维度越大，独立分量点积的方差通常越大，未经缩放的分数可能让 Softmax 过度尖锐、梯度太小。按 √d_k 缩放能让分数规模更稳定。

Step 5：对每一行做 Softmax。

aᵢⱼ = exp(sᵢⱼ) / Σₖ exp(sᵢₖ)，　Σⱼ aᵢⱼ = 1

Softmax 后每行都非负且和为 1。它不在整个 n×n 矩阵上统一归一化，也不是对每列归一化。为了数值稳定，可以先从每一行分数中减去该行最大值。

Step 6–7：由权重混合 Value。

Z = AV，　zᵢ = Σⱼ aᵢⱼ vⱼ

结果 Z ∈ ℝ^{13×3}。这里是对所有可见位置的 Value 做加权平均，不是取分数最大那个 Token 直接复制。

Attention(Q,K,V) = softmax(QKᵀ / √dₖ + M) V

其中 BERT 标准双向 Self-Attention 的 M=0（忽略 Padding Mask），GPT 的 M 是因果遮挡；被遮挡分数为 −∞，Softmax 后对应权重为 0。

5. Multi-Head：为什么不只算一次？

一个 Head 用一组 W_Q,W_K,W_V 学一种信息联系；不同 Head 可以同时关注语法、邻近词、指代、分隔符等不同模式。课件引用 Clark 等对 BERT Head 的分析（第 30 页），但要理解：Head 的语义不是固定手工规定的，且并非每个 Head 都有可解释的单一功能。

headᵣ = Attention(XW_Qʳ, XW_Kʳ, XW_Vʳ)
MultiHead(X) = Concat(head₁,…,headₕ)W_O

课件玩具 h=2,d_v=3，拼接后是 13×6，再用 W_O(6×4) 投影回 13×4，这样才能与原来的 X 做 Residual Addition。实际 BERT-base：d_model=768,h=12,d_k=d_v=64；拼接 12×64=768。

6. 一个完整 Encoder Layer 的后半段

课件 BERT 栈采用 Post-Norm 的教学写法：

H = LN(X + MultiHead(X))
FFN(hᵢ) = GELU(hᵢW₁+b₁)W₂+b₂
Y = LN(H + FFN(H))
  • Residual Connection X + …：保留原始信息，并让梯度更容易跨层传播。
  • LayerNorm：稳定表示的尺度；Post-Norm 是先加 Residual，再归一化。
  • Feed-forward Network（FFN）：对每个 Token 的向量独立使用同一套两层线性网络，中间用 GELU；它混合特征维度，不直接进行跨 Token 交流。
  • 堆叠 N 层：前一层输出是下一层输入，Token 的语义表示逐层变成上下文化表示。

BERT-base（课件）：12 层、768 维、12 Heads、FFN=3072、约 110M 参数、原版位置上限 512；BERT-large 是 24 层、1024 维、约 340M。

7. BERT 怎么训练？怎么应用？

Masked Language Modelling（MLM）：随机遮挡部分 Token，模型借助左右上下文去预测正确 Token；把隐藏向量送入 Vocabulary 分类 Head，再与真实 Token 计算 Cross-Entropy。原版 BERT 还训练 Next Sentence Prediction（NSP），判断 B 是否紧随 A；后续 RoBERTa/ModernBERT 等不一定保留 NSP。

Fine-tuning：预训练参数复用 + 小任务头。 分类可以用 [CLS] 的隐藏向量，NER 对每个 Token 预测标签，Extractive QA 则让两个 Head 分别预测答案的开始和结束位置。医学应用如 BioBERT 依然是 Encoder，特别之处在于继续使用领域文本预训练，而不是把它变成 GPT。

任务 读哪个输出 预测什么
整句分类 [CLS] 对应的最终向量 类别概率
NER / POS 每个 Token 的向量 每个 Token 的标签
抽取式问答 问题与文章的联合表示 文章中答案起始、结束的索引
Search / Ranking 查询、文档的表示或联合输入 相似度或相关性
MLM 预训练 被选为 Mask 的位置 原词表中的目标 Token

原版的输入限制为何是 512 Token？ BERT-base 使用 512 个学习到的位置条目，并且按该范围训练；即便改了位置表，密集 Attention 的 n² 成本仍然存在。课件还介绍 ModernBERT（第 45 页）：8192 长度、RoPE、局部+每隔几层全局 Attention、更现代的 FFN 和训练方法。

高频易错：BERT 的双向可见性不等于“可以自然地像 GPT 一样连续聊天”；MLM 是填空的训练目标，模型不是原生的左到右生成器。`[CLS]` 是输入特殊 Token，分类头只是常见用法，不表示每个 BERT 任务都只能读 `[CLS]`。

03 · GPT：Causal Decoder 与下一 Token 预测

对应课件第 49–76 页

1. GPT 和 BERT 真正只差一个 Mask 吗？

它们共享“Embedding → 注意力 → FFN → 残差 → 归一化”的基本组件，但可见性、训练目标、使用方式都有明显差异。GPT 的目标是给定前缀 x₀,…,x_t，预测 x_{t+1}：

P(x₀,…,xₙ) = ∏ₜ P(xₜ | x₀,…,xₜ₋₁)

这叫 Autoregressive factorisation（自回归分解）。例如已见 the animal didn't cross the street because it was too，模型要预测 tired，不能读取还没出现的 tired。

课件以 GPT-2 风格 Pre-Norm Decoder 为例，输入用 Token 和 Position Embedding（不需要 BERT 那样的 [CLS]、[SEP] 及 Segment Embedding）。相较于 BERT 的 Post-Norm，本例在每个子层前先归一化：

X′ = LN(X)，　H = X + MaskedMHA(X′)
Y = H + FFN(LN(H))

最后还做 Final LayerNorm，线性映射到词表大小，然后 Softmax。要记住：Pre-Norm / Post-Norm 是组件的顺序，不是 Encoder / Decoder 的绝对定义；这里是课件中 BERT 与 GPT-2 实例的对比。

2. Causal Mask 为什么有效？

先算 S = QKᵀ/√d_k，然后加上 Mask：

Mᵢⱼ = 0（当 j ≤ i）；　Mᵢⱼ = −∞（当 j > i）
A = softmax(S + M)，　Aᵢⱼ = 0（当 j > i）

例如长度 4 的 Token 序列，允许关注矩阵是下三角形：第 1 行仅能看第 1 个 Token；第 2 行看前两个；第 4 行能看所有前四个。防泄漏原则：训练时完整输入虽已知，但每一行预测只依赖对应的过去前缀。

对比题常见陷阱：“GPT 只能逐 Token 顺序训练”是错误的。在已给出完整训练序列、且使用因果遮挡时，所有时间位置的 Q/K/V、Softmax 和 Loss 可以并行计算。真正必须循环的是**自回归生成新 Token**。

3. GPT 的 Head、FFN 和输出层

每一个 Masked Attention Head 仍是同样公式，只是多了 M。Multi-Head 拼接后由 W_O 混合。课件介绍了 Induction Heads：若上下文此前出现 Harry Potter，后来再次遇到 Harry，某些 Head 能利用“上次 Harry 后面是什么”的匹配，帮助预测 Potter。这说明多层注意力能学到简单的上下文复制和模式续写机制，但并非所有 Head 都是 Induction Head。

模型最后对某位置向量 y_t ∈ ℝ^{d_model} 算词表 Logits：

ℓₜ = yₜ W_vocab + b，　pₜ = softmax(ℓₜ)

若词表为 |V|，则 W_vocab 可表示成 d_model×|V|，每个位置得到 |V| 个概率。课件示例使用 Eᵀ 作为输出投影（Weight Tying，输入 Embedding 表与输出映射共享参数）：ℓ = Y Eᵀ。

4. Next-token Loss：为什么标签要右移？

假设训练文本为 [the, animal, didn't, cross]。每个位置看到的输入和应当预测的正确目标为：

输入位置所见 Token 正确目标（下一 Token）
the animal
animal didn't
didn't cross
cross 后续 Token 或结束标记

这里的“右移”是输入与目标序列的对齐关系，不是把下一 Token 的真实答案放入当前 Query 的可见输入中。

若模型赋予正确 Token 的概率为 p_t，单位置 Cross-Entropy 为 −ln(p_t)：

L = − Σₜ ln P(xₜ₊₁ | x₀,…,xₜ)

实际训练一般对有效 Token 的损失求平均，并忽略 Padding 位置。反向传播同时更新 Embedding、W_Q/W_K/W_V/W_O、FFN、Norm 等模型参数。

小例子：三个真实目标分别得到概率 0.8、0.5、0.25。平均损失为 −(ln0.8 + ln0.5 + ln0.25)/3 ≈ 0.768。这并不是 1 − 平均准确率。

5. 生成策略：Greedy、Sampling、Temperature、Top-k、Top-p

训练完后，GPT 反复执行：当前前缀 → 输出末尾位置概率 → 选择一个 Token → 把它添加到上下文 → 再运行。

  • Greedy：每次取最大概率。稳定、可复现，但可能重复或缺少多样性。
  • Sampling：按整个概率分布随机抽样，允许多样化输出。
  • Temperature：对 Logits 除以 T 后 Softmax；T<1 分布变尖，T>1 变平（不是对已归一化概率随意除以 T）。
  • Top-k：仅在概率最高的 k 个候选中重新归一化并抽样。
  • Top-p / Nucleus：选择从高到低累积概率至少达到 p 的最小候选集合，再抽样。

6. 从 GPT 到对话助手

课件把语言模型发展分为三个概念层次：Pre-training（下一个 Token 预测）→ Instruction / Preference Post-training（让输出更符合指令与偏好）→ 某些模型的 Reasoning-oriented RL（可检查问题上的强化学习）。InstructGPT 课程中的典型流程为：监督示例微调 → 人类偏好训练奖励模型 → PPO 优化。

GPT 也可以生成代码：预测下一个 Token 的机制不变，只是训练数据和输出任务变成代码。课件用 Codex 与 HumanEval 说明，生成看似合理的代码不等于单元测试通过。阅读第 73–74 页题例时，要特别注意要求的边界条件，例如 y 只在字符串末尾算元音等。

7. 缓存有什么作用？

生成第 t+1 个 Token 时，之前位置在同层得到的 Key/Value 可以缓存（KV Cache），无须把每个旧位置重新计算一遍。这样每步仍需让新 Query 与已有 t 个 Key 比较，故每层的缓存容量大致随上下文长度线性增长，以及新 Token 的注意力计算随 t 增长。KV Cache 解释了为什么生成长文本时显存与速度成为问题，也是 Hybrid / Mamba 要解决的核心问题之一。

04 · 原始 Encoder–Decoder：翻译时如何协作

对应课件第 78–87 页

1. 三个 Attention 不能混为一谈

原始 2017 Transformer 有一个 Encoder 栈和一个 Decoder 栈。课件的翻译例子是 the black cat → le chat noir（法语形容词位置不同）。三种 Attention 的来源分别为：

操作 Q 来源 K 来源 V 来源 Mask / 作用
Encoder Self-Attention 英文 Encoder 英文 Encoder 英文 Encoder 双向理解英文
Decoder Masked Self-Attention 法文 Decoder 当前前缀 同一法文前缀 同一法文前缀 不能看未来法文
Decoder Cross-Attention 法文 Decoder 英文 Encoder 输出 英文 Encoder 输出 查找输入中的相关词

为什么 Cross-Attention 不直接把中英文一起送给 Decoder？ Encoder 先为所有英文位置生成双向上下文化表示，Decoder 再根据当前法文前缀动态查询它们；这是输入与输出分别建模的一种明确、可解释的结构。

2. 位置编码：原始论文使用 Sinusoidal Encoding

原始 Transformer 的每个位置 i 和特征对 c 采用：

PE(i,2c) = sin(i / 10000^{2c/d_model})
PE(i,2c+1) = cos(i / 10000^{2c/d_model})

d_model=4 时：PE(i)=[sin(i), cos(i), sin(i/100), cos(i/100)]。例如 i=2 近似 [0.91, −0.42, 0.02, 1.00]（弧度制）。高频分量区分近邻，低频分量提供更长跨度的位置变化。

课件还强调原始模型输入层做 √d_model · Embedding + PositionalEncoding；在示例 d_model=4 时就是 2E+PE，不同于 BERT 示例中的简单相加。正余弦编码公式无需学习每个位置的单独参数，但不代表一个未在超长文本上训练的模型一定能在任意长度上可靠工作。

3. Shift Right 与 Teacher Forcing

完整目标 le chat noir 已知时，Decoder 输入为 〈s〉 le chat，预测目标为 le chat noir，整体右移一位。因果 Mask 确保第 i 位不能读取第 i+1 位的目标。

Training：目标 Token 全部已知，可一次并行训练三个位置。Inference：先从 〈s〉 生成 le，下一步用 〈s〉 le 生成 chat，再生成 noir。此时 Encoder 对英文原句通常只需要计算一次，后续重复使用其输出。

4. Cross-Attention 的尺寸计算

若英文有 n_s=3 个 Token，法文输入前缀有 n_t=3 个位置，且 Head 宽度 d_k：

Q = H_dec W_Q ∈ ℝ^{n_t×d_k}
K = Y_enc W_K ∈ ℝ^{n_s×d_k}，　V = Y_enc W_V ∈ ℝ^{n_s×d_v}
A_cross = softmax(QKᵀ/√d_k) ∈ ℝ^{n_t×n_s}
Z_cross = A_cross V ∈ ℝ^{n_t×d_v}

矩形是合理的！ 如果目标有 5 个位置、源语言有 8 个，则 Cross-Attention 权重是 5×8，不需要两侧 Token 数量相同。课件第 83 页给出了“法文行查询英文列”的具体数值图。

5. 最终如何输出？

原始 Decoder 每层包含三组子层：Masked Self-Attention → Add&Norm → Cross-Attention → Add&Norm → FFN → Add&Norm。最终隐藏向量经线性层到词表 Logits，经过 Softmax 选出下一个法文 Token。课件小模型在三个目标位置分别有 0.94、0.96、0.96 的正确词概率，对应 −ln 损失求和约 0.14（第 85 页）。

6. 论文为什么认为 Self-Attention 有优势？

课件第 87 页在特定简化设定下比较：Self-Attention 每层计算 O(n²d)，顺序依赖步骤 O(1)，两个位置的最短信息路径 O(1)；传统 Recurrent Layer 每层计算 O(nd²)，时间方向顺序依赖 O(n)，最长路径 O(n)。因此当 n < d 时，Self-Attention 的主导乘法在这一简化比较中可能比 Recurrent 更少，但这不是所有硬件、所有序列长度都更快的证明。

05 · Long Context：Sparse、Flash、Linear Attention

对应课件第 89–95 页

1. 先分清三个“节省”的方向

这部分最容易考“哪一个是真的线性复杂度”和“FlashAttention 是否近似”。

方法 改变什么 核心复杂度 / 内存结论 代价
Sparse Attention 只计算某些 Query–Key 对 O(nk)，每 Token 约 k 条联系 未选中的直接联系被忽略
FlashAttention Tile 分块，改 GPU SRAM/HBM 数据流 仍计算精确 Softmax Attention，主算术仍约 O(n²d)；无需显式保存完整 n² 权重表 实现复杂、硬件相关
Linear Attention 用核特征 φ 替代 Softmax 相关形式，重排乘法 固定特征宽度时可随 n 近似线性，维护固定大小状态 不完全等价于 Softmax，精确查找能力可能下降

普通因果 Self-Attention 在一层一 Head 对 n 个位置大约需要 n(n+1)/2 个有效配对。例如 n=100,000，大约有 5×10⁹ 个位置对；若每个分数采用 16-bit，单个完整三角分数表就约 10 GB（课件第 89 页的估算），尚未包括其他 Head、层和梯度。

2. Sparse Attention：更少的配对

Longformer：让大多数位置只看附近的窗口，同时保留少量 Global Tokens；BigBird 额外引入 Random Links；二者的目标是在长序列中减少直接配对并保留远距离的信息路径。若每个位置有窗口 w、全局链接 g、随机链接 r，常用近似为：

计算配对数 ∝ n(w + g + r)

课件还讨论 Native Sparse Attention（NSA） 与 DeepSeek Sparse Attention（DSA） 的思路：不是只用固定窗口，而让模型先评估哪些块/哪些 Token 更值得精确读取。概念上的取舍是：先做廉价筛选，之后在少数候选上做精细注意力。

3. FlashAttention：省的是内存流量，不是偷偷少算

GPU 的 HBM 容量大但数据搬运慢，片上 SRAM 小但速度快。FlashAttention 将 Q、K、V 分块载入 SRAM，在 Tile 内计算局部分数，使用在线 Softmax 的归一化量累积最终输出，在反向传播时可重算中间值，避免把整个 n×n 中间矩阵反复写回 HBM。

因此它和普通 Softmax 的数学目标一致（容许不同浮点舍入误差），并没有自动将 O(n²) 算术变为 O(n)。课件第 92–93 页还介绍 FlashAttention-2、3、4，重点分别是并行分工、异步执行/低精度，以及更新硬件上的 Kernel Pipeline。

4. Linear Attention：用矩阵乘法结合律重排

标准注意力因为中间有按行的 Softmax，不能简单把 Q(KᵀV) 当作相同结果。Linear Attention 引入特征变换 φ，使非负相似度近似为 φ(q)ᵀφ(k)，从而重排：

(φ(Q) φ(K)ᵀ) V = φ(Q) (φ(K)ᵀ V)

令特征宽度为 d、Value 宽度也约 d，括号内 φ(K)ᵀ V 是 d×d 而不是 n×n；随序列累积一个状态：

Sₜ = Sₜ₋₁ + φ(kₜ) vₜᵀ

为了保留加权平均的归一化，完整形式还维护 zₜ = zₜ₋₁+φ(kₜ)：

outputₜ = [φ(qₜ)ᵀ Sₜ] / [φ(qₜ)ᵀ zₜ]

这是“教学补充”的完整归一化形式，帮助理解为什么不仅要存 S，还要存分母。课件举了 φ(x)=ELU(x)+1，如 φ([0.5,−1])≈[1.50,0.37]。相同宽度下线性状态像一本小笔记本：高效保存总体信息，但多个不同 Key 的 Value 会叠加，精确回忆很久以前某个细节可能变难。

5. 一个判断口诀

Sparse：少看一些；Flash：都看，但搬数据更聪明；Linear：换数学，把历史压缩为状态。 三者也能组合：例如一部分层采用局部/稀疏，部分层使用 Flash Kernel；它们不是互斥的模型大类。

06 · Mamba 与 State-Space Models：把过去压进状态

对应课件第 97–108 页

1. SSM 想实现什么？

在 GPT 里，新 Token 的 Query 往往要与大量过去的 Key 比较；在 Mamba 中，每层只维护一个固定大小的状态。目标是：训练像 Transformer 一样能做并行算法，生成像 RNN 一样只更新少量状态。

先看最简化的离散 State-Space Model（SSM）：

hₜ = Ā hₜ₋₁ + B̄ xₜ，　yₜ = C hₜ

h_t 是内部记忆；Ā 决定旧状态留多少，B̄ 决定本次输入写入多少，C 决定怎样从状态读出输出。它与 Vanilla RNN h_t=tanh(W_hh h_{t−1}+W_xh x_t+b) 的重要区别是：状态更新对过去状态是线性的（没有逐步套入 tanh）。

固定参数情况下，展开递推：

hₜ = Āᵗ h₀ + Σₖ₌₁ᵗ Āᵗ⁻ᵏ B̄ xₖ

因此每个旧输入经 Ā 的不同幂衰减。若每一步的变换是线性的或仿射的，多步状态转换可以通过结合律并行 Scan；这也是 Mamba 的 Sequence Parallelism 思想来源。注意：它并非把所有递推依赖“从数学上删掉”，而是利用特殊结构给出可并行的计算算法。

2. 为什么固定遗忘率不够？

课件引入连续状态离散化的 Step Size Δ。若单一状态分量的连续参数 A<0，则：

Ā = exp(ΔA) = exp(−Δ|A|)
  • Δ 很小：Ā≈1，保留旧记忆多、写入新内容少。
  • Δ 很大：Ā≈0，快速忘掉旧记忆，允许新的信息替换它。

以 |A|=1 为例：Δ=0.01 时 Ā≈0.99；Δ=1 时 Ā≈0.37；Δ=2 时 Ā≈0.14。如果所有 Token 都用同一个 Δ，既要记住关键名字，又要忽略大量无关词，会非常困难。

Mamba 的 Selection 机制：让 Δ_t、B_t、C_t 都依赖当前 Token 的内容，即状态何时记、记什么、读什么可以变化，而不仅仅把整段历史等比例衰减。

Δₜ = softplus(W_Δ xₜ + b_Δ)，　Bₜ=W_B xₜ，　Cₜ=W_C xₜ
hₜ = Āₜhₜ₋₁ + B̄ₜxₜ，　yₜ=Cₜhₜ

softplus(u)=ln(1+eᵘ)>0 保证 Δ_t 为正。课件第 106 页进一步列出了通过连续参数 A 和 Δ_t 计算 Ā_t、B̄_t 的离散化表达式。考核若只需解释架构，能够明确 内容相关的更新 / 选择性遗忘 即已抓住核心。

3. Mamba Block 的八步（按课件第 101 页）

  1. RMSNorm：缩放输入每个 Token 的特征向量，避免尺度不稳定。
  2. Linear Projection：将 D 维投影到更宽的 2D，分成 SSM 主路径和门控支路。
  3. Causal Conv1d：主路径用短窗口的一维卷积整合近邻 Token，提供局部上下文。
  4. SiLU：主路径非线性；SiLU(x)=x·sigmoid(x)。
  5. Selective SSM：长距离信息通过状态递推，并由 Token 产生 Δ、B、C。
  6. Gate：对 SSM 结果与另一分支的 SiLU 输出逐元素相乘，控制哪些通道通过。
  7. Linear Projection：从 2D 投影回 D。
  8. Residual Addition：把输入 x 加回去，便于训练深层网络。

课件第 102 页比较了 RMSNorm 与 LayerNorm：RMSNorm 只按均方根归一化，不减去均值；例如 [2,−1,0,3] 的均方根是 √3.5≈1.87，RMSNorm（取 g=1）输出约 [1.07,−0.53,0,1.60]。RMSNorm 不是在每个特征上做独立的零均值化。

4. Mamba 与 Transformer 的优劣

读取精确的早期 Token 可以用 KV Cache 直接找到 过去已压缩成状态，可能失真

课件第 108 页特别提醒：Mamba 在一些基准和长距离模式任务上有优势，不代表所有需要精确 Copy/Lookup 的任务都优于 Transformer。新课件还提及 Mamba-2 的 SSD 和 Mamba-3 研究方向；它们是该模型族的后续算法变化，不要把所有结果归结为最早的 Mamba-1。

07 · Mixture of Experts（MoE）：参数多但只用一部分

对应课件第 110–111 页

1. Dense 与 Sparse MoE 的差别

在 Dense FFN 中，每个 Token 都走同一个 FFN。MoE 将某些 FFN 子层换成多个可学习的 Expert（每个 Expert 通常也是 FFN），并由 Router 为每个 Token 选择少数专家。这样模型可以有很多参数，但一次只激活其中一部分。

重要的是：MoE 不一定替换 Self-Attention。它经常主要替换 FFN 子层；共享 Attention、Embedding、Norm 仍要执行。

2. Top-k 路由算例：课件的八专家两激活

课件第 110 页设八个 Expert 的 Router Logits 为 [0.5,−1,2,0.1,−0.5,1,−2,0.3]。分数最高的是 Expert 3：2，其次是 Expert 6：1。只在这两个保留 Expert 上做 Softmax：

w₃ = e²/(e²+e¹) ≈ 0.731，　w₆ = e¹/(e²+e¹) ≈ 0.269
y = 0.731·Expert₃(x) + 0.269·Expert₆(x)

注意 Top-k 操作分两步：先根据 Logits 挑选专家，再对入选专家的分数做 Softmax（课件以 Mixtral 的规则示范）。如果先对八个专家 Softmax 再直接取两项，这两项概率和通常不为 1；要看具体路由算法是否还会重归一化。

3. 总参数与激活参数不能混为一谈

课件举的 Mixtral 8×7B：约 47B 总参数，每个 Token 约 13B 被用到。不是“只存 13B 参数”，而是只运行涉及其中部分专家的计算。不同 Token 可以选不同 Expert，因此同一 Batch 的路由、专家负载和硬件通信会影响实际效率。

教学补充 · MoE 的工程问题：若大量 Token 都偏好同一专家，可能发生专家拥塞，其他专家训练不足；实际系统常用路由平衡策略和容量管理。但这些细节不是课件第 110–111 页的重点；考试优先掌握 Router、Top-k、Active vs Total Parameters 的定义及简单算例。

08 · Hybrid Architectures：为什么全注意力与状态模型要混用

对应课件第 113–119 页

1. 一本“书”和一本“笔记本”

课件用非常好记的比喻：Attention 像一整本打开的书，过去每个 Token 的 Key/Value 仍在，能按需查阅，但缓存随文本增长；SSM / Linear Attention 像一本固定大小的笔记本，写入和读取快，但无法无限制保留每条具体事实。Hybrid 在大多数层使用“笔记本”，在少数层保留“书”。

需求例 1：理解 100 万 Token 小说的大致主题，压缩状态往往很有用。需求例 2：从前面 1000 个电话号码中找到某个人的精确数字，少量 Full Attention 对精确查找更重要。

2. Full Attention 与 Sliding Window

Full Attention：第 t 个位置可看到所有旧 Token；它的 KV Cache 长度随 t 增长。Sliding-Window Attention：只看最近的 w 个 Token，缓存可限制为 w，全序列总配对量约 O(nw)。它能精确回忆窗口内细节，但较远的 Token 只能依靠跨层传播或其他模块；局部注意力不等于直接拥有无限全局记忆。

3. 讲义中的代表性混合方法

架构 混合方式（按课件） 想解决的问题 / 局限
Jamba（2024） 8 层为一组，1 Attention + 7 Mamba；穿插 MoE 少数 Attention 提供精确上下文访问，大多数 Mamba 降低长序列成本
Griffin（2024） 2 Recurrent + 1 Local Attention（窗口约 1024） 固定记忆承载远期概况，短窗精确访问；窗口外直接精确查找较弱
Hymba（2024） 在同一层并行 Attention Heads 与 Mamba Heads；部分全局、其余局部 不同类型的 Heads 分担精确查找和信息压缩
Kimi Linear（2025） 3 Linear-Attention 层 + 1 Full-Attention 层；配合 MoE 大部分层无长 KV Cache，保留少量全局访问
Nemotron 3 Super（课件 2026） 大量 Mamba-2 + MoE，少量 Global Attention Anchor 面向长输出及 Agent 任务控制 Attention 缓存成本

这张表应优先记住设计原则，而非死背所有年份、参数规模。不同 Hybrid 的结构不必完全一样：可在层之间交替（Jamba），也可在同一层内部并排使用多种 Head（Hymba）。

4. 混合结构是否一定优于纯 Transformer？

不是。Hybrid 会增加路由、训练、Kernel 与部署复杂度；对于短文本或需要大量精确 Token-by-Token Copy 的任务，Full Attention 可能仍更合适。比较性能时要尽可能控制模型规模、训练数据、硬件与评测任务，不能仅凭“线性复杂度”就断言它在所有任务上更快、更好。

09 · Diffusion Language Models：不是只向右写，而是反复修改

对应课件第 121–126 页

1. 从图像 Diffusion 的“去噪”理解文本

图像 DDPM 的前向过程逐步给干净图像 x₀ 添加高斯噪声，训练神经网络根据带噪图像 x_t 和噪声步 t 预测加入的噪声 ε。经典训练目标近似为：

L_DDPM = || ε − ε_θ(xₜ,t) ||²

生成时从纯噪声开始，多轮预测并移除部分噪声，逐渐得到清晰图像。关键并非一定是图像，而是定义一个简单的“破坏数据”过程，再学习其逆过程。

2. 为什么文本不直接加高斯噪声？

文本 Token 是离散的 ID，而不是连续像素值，不能把加 0.1 的噪声后 ID 当成合法词。因此离散 Diffusion 的一种办法是 Masking：

  • 前向：按噪声强度 t 将某些位置换成 [MASK]，最终全部 Mask。
  • 训练：模型读带 Mask 的整段序列，预测被 Mask 的原词，通常使用 Cross-Entropy。
  • 逆向生成：从一串 Mask 开始，预测候选 Token，保留置信度较高的结果，其余继续 Mask 并重复。

课件将 D3PM（Discrete Diffusion）与 BERT MLM 联系起来：BERT 的 Masked Prediction 可以视作某个单一固定噪声水平的去噪任务，但 BERT 并不是完整的多步生成式 Diffusion LM。LLaDA 将多步 Mask-and-Refine 用于语言生成。

课件第 124 页的例子是“WHY DIDN’T THE ANIMAL CROSS?”，从全 Mask 开始，把最确定的 tired 等词先填出，经过 4 步写出 It was too tired to cross .。需要注意：模型并非严格从左到右解除 Mask。

3. Diffusion LM 与 GPT 的对照

特征 GPT 自回归 Masked Diffusion LM
生成单元 通常每次 1 个 Token 一步可以提出多个位置的 Token
顺序 左→右，前缀固定 任意位置可反复更新/再 Mask

10 · Rotary Position Embedding（RoPE）

对应课件第 128 页

1. 从绝对位置向量到相对位置的注意力分数

BERT 的学习式位置表和原始 Transformer 的 Sinusoidal Encoding，是将位置向量加到输入表示上。RoPE 不同：对每个 Attention Head 中 Query/Key 的成对特征做旋转；角度取决于 Token 的绝对位置。

二维向量按角度 α 旋转，矩阵是：

R(α) = [[cosα, −sinα], [sinα, cosα]]

某个二维特征对，在位置 i 的 Query 旋转 iθ，位置 j 的 Key 旋转 jθ：

q′ᵢ = R(iθ)qᵢ，　k′ⱼ = R(jθ)kⱼ

注意力分数的点积变成：

q′ᵢ · k′ⱼ = qᵢᵀ R(iθ)ᵀ R(jθ)kⱼ = qᵢᵀ R((j−i)θ)kⱼ

关键结论：旋转后的点积会通过角度差 j−i 感知相对距离。 同一组两个 Token 整体向后平移相同距离，它们之间的相对旋转角不变。

2. 不同频率的多组旋转

对 Head 宽度 d_k 的不同二维分量使用不同频率，课件写成 θ_c = 10000^{−2c/d_k}。较前面的维度转得快，较后面的维度转得慢，与 Sinusoidal 多尺度的直觉相近。

一个小验证：若位置 i=3、Key 位置 j=1，距离为 −2；整体后移 2 到 i=5,j=3，距离仍为 −2。两对在相同内容向量下的相对旋转关系一致。

3. 容易混淆的地方

RoPE 通常作用在 Q 与 K，而不是把旋转直接施加到 Value 或最终输出；它不是一种 Attention 复杂度优化算法，位置感知方式变了，不代表 n² 配对自然消失。RoPE 允许在形式上为更多位置计算旋转，但实际长上下文表现仍依赖训练范围和外推/缩放策略。

11 · Retrieval-Augmented Generation（RAG）

对应课件第 130–131 页

1. 为什么需要 RAG？

语言模型的参数不是实时更新的数据库；模型可能不认识新文件，也可能把不确定的事实“顺畅地说错”。RAG 让模型先从外部文档找到证据，再带着证据回答。这不是新的 Attention 公式，而是一个组合工作流。

2. 两个阶段：建索引与每次问答

离线阶段：收集文档 → 分 Chunk → 用 Embedding Encoder 将每段转成向量 → 记录在向量索引中。在线阶段：把用户问题也转成 Query 向量 → 算与候选段落的相似度 → 取 Top-k → 将问题和检索段落放到 Decoder 的 Prompt 中 → 生成答案。

Encoder/Decoder 分工是概念模型：课件以 BERT-like Encoder 与 GPT-like Decoder 展示实际协作。现实中也可采用不同独立模型做嵌入、重排和生成，具体实现不一定由原版 BERT 直接完成。

3. Cosine Similarity：必须会手算

cos(q,d) = (q · d) / (||q||₂ ||d||₂)

课件第 131 页用“澳大利亚首都是哪里？”作例：q=[0.8,0.5,0.1,0.2]，与 Canberra 文章的向量 [0.7,0.6,0.2,0.1] 点积是 0.90，两者长度约 0.97、0.95，相似度约 0.98。课件中的 Sydney 段落约 0.60，Paris 段落约 0.58，因此选 Canberra 段落进入 Prompt。

余弦相似度比较向量方向；若向量已 L2 Normalize，Cosine Similarity 等于 Dot Product。高相似度表示嵌入空间更匹配，不自动证明段落内容真实、更新或足以回答问题。

4. RAG 常见失败源（教学补充）

  • Chunk 分错：答案跨越两个 Chunk，单个段落不完整。
  • Retrieval miss：正确段落没有进入 Top-k；生成模型只能靠不充分的上下文回答。
  • Stale source：检索到旧版本材料，答错最新事实。
  • Grounding failure：找到了证据，生成时却误读或无视证据。

因此可靠 RAG 应当尽可能展示检索来源并控制模型“超出材料的补充”，不是加了检索就自动消除 Hallucination。

题 02基础·RNN 与 Attention4 分

为什么在序列 The dogs that the cat chased were ... 中，标准 Self-Attention 比普通 RNN 更容易直接关联 dogs 与 were？这是否意味着生成时 Transformer 一定能并行输出整个句子？

题 04计算·LayerNorm4 分

对一个 Token 的二维向量 x=[1,3]，忽略 ε、γ=1、β=0，算其 LayerNorm 输出；说明均值和标准差是沿哪个维度求的。

展开参考答案与解题思路⌄

题 06计算·一次完整 Attention8 分

单个 Head 中：q₁=[1,0]，k₁=[1,0]，k₂=[0,1]，v₁=[2,0]，v₂=[0,4]，d_k=2。无 Mask。求第 1 个 Token 的 Scaled Scores、Softmax Weights 和输出 z₁（三位小数）。

展开参考答案与解题思路⌄

① s₁₁=q₁·k₁/√2=1/√2≈0.707；s₁₂=0。② Softmax：exp(0.707)≈2.028，exp(0)=1，故 a₁₁≈2.028/3.028=0.670，a₁₂≈0.330。③ 对 Value 加权：z₁=0.670[2,0]+0.330[0,4]≈[1.340,1.321]。若把 K 加权就是错误解法。

题 07计算·Causal Mask6 分

第 2 个 Token 对四个 Key 的原始 Logits 为 [1,0,5,8]。按 1-based 位置计算，使用 Causal Mask 后进行 Softmax，求四个权重。说明第 3、4 个 Token 是否能得到非零权重。

展开参考答案与解题思路⌄

第 2 个 Query 只能看 Key 1、2，Mask 后 [1,0,−∞,−∞]。Softmax 结果 [e/(e+1),1/(e+1),0,0]≈[0.731,0.269,0,0]。未来 Key 3、4 即使原分数高，Mask 后 exp(−∞)=0。

题 08解释·√d_k 的意义4 分

为什么 Scaled Dot-Product Attention 要使用 QKᵀ / √d_k，如果不缩放且维度越来越大会发生什么？

展开参考答案与解题思路⌄

点积是 d_k 个分量乘积的和；在常见近似独立、相似尺度假设下，方差随 d_k 增长。未缩放的 Logits 易变得绝对值很大，使 Softmax 极度尖锐、许多梯度接近零。除以 √d_k 让分数尺度较稳定。注意不是为了保证结果在 [−1,1]，也不是在对向量求 Cosine。

题 09计算·Multi-Head 连接5 分

课件玩具 BERT 有两个 Head，每个 Head 输出 13×3，最终 d_model=4。为什么不是把两个 Head 相加？应该如何组合，W_O 尺寸应是多少？

展开参考答案与解题思路⌄

把两组输出按特征维度拼接得 13×6；再乘 W_O∈ℝ^{6×4} 得 13×4，与原输入形状一致。拼接保留不同 Head 的各自特征；W_O 学习跨 Head 的组合。直接相加会过早混合不同特征，且不是课件定义的标准 Multi-Head 结构。

题 10概念·FFN 与 Attention4 分

在 Encoder Layer 中，FFN 是否让 Token i 直接读取 Token j？为什么需要 FFN 和 Residual Connection？

展开参考答案与解题思路⌄

标准逐位置 FFN 对每个 Token 的向量单独应用同一组 W₁, W₂ 及激活函数；它混合同一 Token 内部的特征维度，不直接在不同 Token 之间传播信息。跨 Token 传播主要由 Attention 实现。Residual 保留原表示、给梯度提供较短路径，帮助训练深层模型。

题 11判断·Pre-Norm / Post-Norm4 分

以下两式有何区别：A LN(x+Sublayer(x))，B x+Sublayer(LN(x))？课件分别把哪一个用于 BERT 和 GPT-2 的示范？

展开参考答案与解题思路⌄

A 是 Post-Norm：先做子层输出与 Residual 相加，再归一化；课件 BERT Encoder 示例用此顺序。B 是 Pre-Norm：先归一化再进入子层，输出与未归一化的 Residual 相加；课件 GPT-2 Decoder 示例用此顺序。这是两个具体实现的对比，不能得出“所有 Encoder 必 Post、所有 Decoder 必 Pre”的结论。

题 12概念·MLM 与 Next-Token5 分

解释 BERT 的 MLM 与 GPT 的 Next-token Prediction：训练标签分别从何而来？两者为何通常拥有不同的 Attention Mask？

展开参考答案与解题思路⌄

MLM 遮挡训练文本部分 Token，用该位置左右上下文预测被隐藏的原 Token，使用双向 Attention；GPT 对每个位置预测下一个 Token，由已知文本自动形成 input-prefix→target-next 的标签，使用 Causal Mask 避免读取目标答案。两者都可通过 Cross-Entropy 优化，但预训练目标、可见性和自然生成方式不同。

题 13计算·Cross-Entropy5 分

模型在三个正确的下一 Token 上给出的概率分别为 0.8、0.5、0.25，求平均 Negative Log Likelihood（自然对数），并解释为什么不能用准确率代替。

展开参考答案与解题思路⌄

L=−(ln0.8+ln0.5+ln0.25)/3≈−(−0.2231−0.6931−1.3863)/3≈**0.7675**。即使三个位置的最大概率 Token 全部正确，不同置信度仍给出不同 Loss；Cross-Entropy 利用正确类别的概率强度而不只记录对/错。

题 14计算·Cross-Attention 尺寸6 分

翻译模型有 7 个源语 Token、4 个目标前缀位置、单 Head d_k=16,d_v=32。求 Cross-Attention 的 Q、K、V、Score 和输出形状，并说明哪个矩阵的行来自目标端。

展开参考答案与解题思路⌄

Q 来自 Decoder：4×16；K 来自 Encoder：7×16；V 来自 Encoder：7×32。QKᵀ 是 4×7，Softmax 后仍是 4×7，乘 V 得 4×32。因此每行是一个法文/目标查询位置，每列是一个源语位置。Cross-Attention 不要求源和目标序列一样长。

题 15计算·Sinusoidal Encoding5 分

原始 Transformer 中 d_model=4。写出位置 i 的四维正弦位置向量，代入 i=2（三位有效数字）。它与 BERT 学习式位置表有何本质区别？

展开参考答案与解题思路⌄

PE(i)=[sin(i),cos(i),sin(i/100),cos(i/100)]。位置 2 的向量约为 [0.909,−0.416,0.0200,1.000]。原始论文按固定函数计算位置，无需学习每个位置一行；BERT 原版使用可学习的位置 Embedding 表。二者都在输入阶段提供顺序信息。

题 16概念·Teacher Forcing5 分

已知翻译 the black cat → le chat noir，写出训练时 Decoder 的输入与标签。为何训练可以并行三个位置而推理必须按步骤生成？

展开参考答案与解题思路⌄

输入为 〈s〉 le chat；标签为 le chat noir。训练时目标序列全部已知，三个位置可同时输入，Causal Mask 阻止位置看到未来的标签；推理时下一 Token 尚未知，先 〈s〉→le，接着 〈s〉 le→chat，再到 noir。Encoder 对源句的输出通常能被复用。

题 17判断·长上下文效率6 分

判断并解释：A FlashAttention 把精确 Self-Attention 的核心算术从 O(n²) 变成 O(n)；B Sparse Attention 让每个 Token 只与部分 Token 建立直接关系；C Linear Attention 与 Softmax Attention 在数学上完全一致。

展开参考答案与解题思路⌄

A 错：FlashAttention 通过分块与在线 Softmax 减少 HBM 内存往返和 n² 中间表，通常仍计算二次量级的配对。B 对：窗口、全局、随机、可学习选择都可减少直接配对。C 错：Linear Attention 通过核特征改变相似性/归一化计算，通常不是原始 Softmax 的精确等价；其代价之一是固定状态中的记忆重叠。

题 18计算·复杂度增长4 分

假设一个 Head 的标准全注意力有效配对数按 n² 估算。序列长度由 1,000 增至 10,000，配对数增加多少倍？若每个位置只有固定 128 个邻近 Key，则配对数增加多少倍？

展开参考答案与解题思路⌄

密集注意力比值 (10000²)/(1000²)=**100 倍**。固定窗口近似 n×128，故比值 10000/1000=**10 倍**。这只是配对次数，不等于实际端到端运行时间必然恰好提高 100 倍或 10 倍，硬件利用率和其他算子也重要。

题 19原理·Linear Attention6 分

为什么普通 Softmax Attention 不可以随意变成 Q(KᵀV)？Linear Attention 如何利用结合律减少中间矩阵，可能牺牲什么能力？

展开参考答案与解题思路⌄

标准 Attention 是 softmax(QKᵀ/√d_k)V，中间有按行非线性 Softmax，不能从乘积结构直接改成 Q(KᵀV)。线性 Attention 用 φ(q)ᵀφ(k) 等可分离特征形式，先累积 S=Σ φ(k)vᵀ 和归一化分母状态，使状态大小独立于文本长度。代价是不同 Key/Value 叠加，复杂的精确检索和 Copy 可能不如保留逐 Token KV 的 Softmax。

题 20计算·SSM 的递推5 分

简化单维 SSM：h_t = 0.9 h_{t−1}+0.1x_t，初值 h₀=0，输入依次为 [10,0,0]。计算 h₁,h₂,h₃，并解释这与状态遗忘有什么关系。

展开参考答案与解题思路⌄

h₁=0.9×0+0.1×10=1；h₂=0.9×1+0=0.9；h₃=0.9×0.9=0.81。新输入为零时，记忆以 0.9 倍逐步衰减。Mamba 的关键不同之处是让保留/写入/读取参数能够随当前 Token 变化，而不是所有位置一直使用同一个 0.9。

题 21计算·RMSNorm5 分

输入向量 x=[2,−1,0,3]，设 g=1 且忽略 ε。求 RMSNorm，并与 LayerNorm 的主要区别比较。

展开参考答案与解题思路⌄

RMS=√((4+1+0+9)/4)=√3.5≈1.871；输出约 [1.069,−0.535,0,1.604]。RMSNorm 仅除以均方根（再乘学习缩放系数），而 LayerNorm 还会先减去均值，并可使用学习偏置 β。课件示范的 LayerNorm 结果约 [0.63,−1.27,−0.63,1.27]。

题 22计算·MoE Top-26 分

八个 Expert 的 Logits 中只有 E3、E6 入选，Logits 分别为 2、1。若 E3(x)=[2,0]、E6(x)=[0,4]，按入选两项重新 Softmax 后求输出向量。

展开参考答案与解题思路⌄

路由概率 w3=e²/(e²+e¹)≈0.7311、w6≈0.2689。输出 y=w3[2,0]+w6[0,4]≈**[1.462,1.076]**。其余 6 个 Expert 没有参与此次 Token 的 FFN 计算。重点是 Top-k 选择、入选权重的归一化和加权混合。

题 23应用·Mamba vs Attention6 分

任务 A：从非常长的文章中记住整体主题；任务 B：从前面 1000 组号码中精确复制第 413 组。为什么 Mamba 与 Full Attention 可能各有优势？Hybrid 如何兼顾？

展开参考答案与解题思路⌄

A 是长期压缩摘要问题，SSM 的固定大小状态、线性序列处理和低缓存成本可能更有利；B 是随机精确查找问题，Full Attention 仍能用每个历史 Token 的 Key/Value 查询，通常更适合。Hybrid 主要用 Mamba/Linear 保留廉价长期状态，少量 Full Attention 提供必要的精确检索，但性能取决于任务和训练。

题 24概念·Diffusion LM5 分

比较 GPT 与 Masked Diffusion LM 的生成过程：假设输出有 8 个位置，为什么 Diffusion LM 有可能 4 个步骤内得到完整句子？“4 步”是否意味着只运行一个前向过程？

展开参考答案与解题思路⌄

GPT 典型自回归生成通常每轮追加一个 Token；Masked Diffusion LM 可一轮同时预测多个 [MASK]，保留若干确定位置，多轮逐步修正，因此 8 个位置可能分 4 次完善。4 步通常意味着多轮模型计算，不是一次前向就生成全部内容，也不保证固定步数下品质优于 GPT。

题 25推导·RoPE 相对位置7 分

用旋转矩阵性质说明，为什么对 Query 和 Key 分别转 iθ、jθ，其点积只通过 j−i 感知相对位置。若两个位置分别从 (3,1) 平移到 (5,3)，相对角改变了吗？

展开参考答案与解题思路⌄

q′ᵢᵀk′ⱼ=qᵢᵀR(iθ)ᵀR(jθ)kⱼ。因为旋转矩阵 R(a)ᵀ=R(−a) 且 R(−a)R(b)=R(b−a)，得到 qᵢᵀR((j−i)θ)kⱼ。两对位置 (3,1) 与 (5,3) 都有 j−i=−2，相对角相同。RoPE 改的是位置表示，不会自动把二次 Attention 变为线性。

题 26计算·RAG Cosine6 分

问题向量 q=[3,4]，候选段落 A 的向量 [6,8]，候选 B 的向量 [4,−3]。分别算 Cosine Similarity，应该优先检索哪一段？相似度高是否代表段落事实一定正确？

展开参考答案与解题思路⌄

||q||=5、||A||=10、q·A=18+32=50，cos(q,A)=50/(5×10)=1；||B||=5、q·B=12−12=0，cos(q,B)=0。A 排在 B 前。但 Cosine 只度量向量在 Embedding 空间中的方向接近程度，不能验证内容的真实性和时效性。

题 27综合·完整模型追踪10 分

一个 Decoder-only Transformer 接收 n=6 Token，隐藏维 d_model=12，3 Heads，各 d_k=d_v=4。请从输入到输出列出矩阵维度，并指出在哪一步阻止未来 Token 被读取。

展开参考答案与解题思路⌄

输入 X:6×12。每 Head W_Q/W_K/W_V:12×4，Q/K/V:6×4；QKᵀ:6×6；在 Softmax 前为 S 添加 6×6 的Causal Mask，未来列设为 −∞；权重 A:6×6，Z=AV:6×4；拼接 3 Head 得 6×12，乘 W_O:12×12 回到 6×12；Add/Norm 与 FFN 后经 Output Projection 得 6×|Vocab| 的 Logits，训练时每行对齐下一 Token 标签。推理时只用末尾位置的概率选择下一 Token。

题 28综合·选架构与论证10 分

你要设计一个可阅读 20 万 Token 技术日志、回答精确行号问题、并生成较长总结的系统。比较 Full Attention、纯 Mamba、Hybrid、RAG 四种方案的相对优缺点，并给出理由充分的组合方案。

展开参考答案与解题思路⌄

Full Attention 可精确回看上下文，但 20 万 Token 的配对与 KV 成本高；纯 Mamba 高效维护压缩状态，精确行号/原文 Copy 可能丢失；Hybrid 以状态层降低成本、少量全局 Attention 处理精确查询；RAG 建索引后只检索相关日志片段，避免每次把整个日志放入上下文。可用方案：按行号与时间保留元数据，日志 Chunk 索引检索 + Rerank，Top-k 片段与明确行号作为证据送入 GPT/Hybrid Decoder，要求引用来源；长总结可分段聚合。此方案是依据课件原理做的设计推导，不是老师指定的唯一答案。
