1什么是贪心算法？它什么时候会错？

定义

贪心算法分阶段构造解；每个阶段只做“当前看起来最好”的那一个选择，不回头、不枚举其他可能。好处：搜索空间大幅缩小、算法通常简单；代价：局部最优不一定导出全局最优，所以必须证明。

课件用“爬山找最高点”打比方：一直沿最陡方向往上爬，一定能到某个山顶，但不一定是最高的那个山顶。

例 1：分数背包 vs 0-1 背包

Fractional Knapsack：物品 i 重 wi、价值 vi，可以取任意比例。贪心：按单位价值 vi/wi 从大到小装，最后一个可能切一部分。这是最优的（后面 Module 3 的“等重量交换”给出了证明）。

2证明贪心正确的三种标准方法

方法 A：Greedy stays ahead（贪心始终领先）
  1. 把贪心解 G = (g1,…,gr) 和任意（最优）解 O = (o1,…,os) 按同一顺序排好。
  2. 选一个进度度量，例如“第 k 个活动的结束时间”。
  3. 对 k 归纳证明：贪心在每一步都不落后（如 f(gk) ≤ f(ok)）。
  4. 最后一步：解释为什么“不落后”推出最优（通常反证：若 s > r，则 or+1 贪心也能选，矛盾）。
方法 B：Exchange argument（交换论证）
  1. 取任意最优解 O。
  2. 找第一个与贪心不同的位置 k（gk ≠ ok）。
  3. 把 ok 换成 gk，证明：仍可行且目标值不变差。
  4. 重复交换，最优解逐步变成贪心解（或包含贪心解），故贪心最优。
方法 C：相邻交换 + 反证（排序类问题专用，本质是 B 的特例）

假设最优顺序不是贪心顺序 ⇒ 一定存在相邻逆序对 (i, i+1)。交换这两个后只有它们俩的贡献改变，算出差值 ≥ 0（或 >0 得矛盾）。像冒泡排序一样消去所有逆序 ⇒ 贪心顺序最优。只交换相邻的：交换不相邻元素会改变中间所有元素的完成时间，难以比较。

考点：如何选择证明方法（课件 §2.2 的结论）
  • Activity selection：“结束得更早”这个性质，两种方法都能用。
  • Prim：“部分树在同等规模下最便宜”这种 stays-ahead 度量是错的（反例见 §4），要用交换：维持“已选边都属于某棵 MST”。
  • Dijkstra：直接比较路径长度（任意竞争路径第一次离开 S 的点）就证完了；硬写交换论证反而要先用到这个结论。
  • 原则：选一个能让“下一步贪心决策安全”的性质——要么是有用的比较量，要么是完整解里的合法交换。

3活动选择 Activity Selection

问题

给 n 个活动 [si, fi)，选出两两不重叠的最多个数的活动。

三个候选规则，只有一个对

规则结论反例思路
最短的先选✗一个短活动正好横跨两个不重叠长活动的交界处：选它会挤掉两个。
冲突最少的先选✗课件给出了特意构造的反例（冲突数最少的活动恰好破坏最优结构）。
结束时间最早的先选（EFT）✓—

证明 1：stays ahead

证明骨架（可直接写在考卷上）

设贪心解 G = {g1,…,gr}、任一最优解 O = {o1,…,os}，都按结束时间排序。

断言：对所有 k ≤ min(r,s)，f(gk) ≤ f(ok)。

基础：g1 是全体中结束最早的，故 f(g1) ≤ f(o1)。

归纳：若 f(gk−1) ≤ f(ok−1)，由于 O 相容，f(ok−1) ≤ s(ok)，所以 ok 与 g1..k−1 都相容，是贪心第 k 步的候选；贪心选了结束最早的候选，故 f(gk) ≤ f(ok)。

最优性：若 s > r，则 f(gr) ≤ f(or) ≤ s(or+1)，or+1 仍可加入，贪心不会停下，矛盾。故 r ≥ s。∎

证明 2：exchange

证明骨架

若 G ⊄ O，令 k 为第一个 gk ≠ ok 的下标。令 O′ = (O \ {ok}) ∪ {gk}，大小不变。可行性：gk 与 o1..k−1 = g1..k−1 相容；又 gk 是与它们相容的活动中结束最早的，故 f(gk) ≤ f(ok) ≤ s(oi)（i > k），与后面也不冲突。反复交换得到最优解 O ⊇ G；若 O 还有 G 之外的活动，它与 G 全部相容，贪心会选它——矛盾。故 O = G。∎

实现与复杂度

按 fi 排序 O(n log n)；扫描时只维护“上一个被选活动的结束时间” last：若 si ≥ last 则选并更新，否则丢弃，O(1)/个。总 O(n log n)。

变体（常考）
  • 所有活动等长、最大化总时长：总时长 = 个数 × d，等价于原问题，贪心仍对。
  • 不等长、最大化总时长（或带权活动）：贪心失效——交换论证依赖“任意活动对目标贡献一样”，这时不成立。要用 DP（weighted interval scheduling）。

4证明策略对比：Prim 与 Dijkstra

Prim：为什么要用交换而不是 stays ahead

Prim：从根 r 出发，每次加一条“连接当前树和新顶点的最便宜边”。

自然但错误的进度断言

“Prim 在每一步都拥有同样顶点数下最便宜的树”——错。课件例：边 ra=4, rb=5, bc=1, ac=10。Prim 前两步选 ra(4)、rb(5) 共 9；另一顺序选 rb, bc 只要 6。两棵都含 3 个顶点，但顶点不同，不能直接比；最终两者都能补成总价 10 的 MST。

正确的不变量（交换）

不变量：已选的边都属于某棵最小生成树 T。设下一条贪心边 e 连接已到达集合 S 与外部。若 e ∈ T 无事；否则 T + e 有一个环，环上必有另一条边 f 也跨越 S 与外部。Prim 当时也能选 f，所以 w(e) ≤ w(f)；T′ = T + e − f 是生成树且不更贵，且 f 不是之前选的边（之前选的边都在 S 内部）。∎

Dijkstra：直接比较路径

见 §9 的完整证明。核心一句话：对选出的 v 和任意 s→v 路径 P，设 P 第一次离开已定集合 S 时到达 y，则 D(v) ≤ D(y) ≤ len(P 到 y 的前缀) ≤ len(P)（非负边权保证后半段不会变短）。

5基站覆盖 Cell Towers 与区间刺穿 Interval Stabbing

问题

一条直路旁有若干房子，基站覆盖半径 5km。放最少的基站使每座房子都在某基站 5km 内。

贪心：自西向东，找第一座未被覆盖的房子 h，在 h + 5 处放基站（尽量往东放，覆盖得最远）；跳过所有被覆盖的房子，重复。已排序 O(n)，否则 O(n log n)。

证明（stays ahead，题目 Q1 也会用到同样思想）

断言：把基站从西到东编号，贪心第 k 个基站 gk 不比任何合法方案的第 k 个基站 ak 更靠西：ak ≤ gk。

基础：若 a1 > g1 = h1+5，第一座房子覆盖不到。

归纳：贪心放 gk 是因为有房子 h = gk − 5 > gk−1 + 5。若 ak > gk，则 ak−1 + 5 ≤ gk−1 + 5 < h < ak − 5，h 夹在 A 的两个相邻基站的范围之间，A 不合法。

最优：若贪心用 r 个，最后一个由房子 h = gr − 5 > gr−1+5 强制；任何只用 r−1 个的方案，最后一个 ≤ gr−1，盖不到 h。∎

抽象：区间刺穿（Interval Stabbing）

房子 x 能被 [x−5, x+5] 内任何基站覆盖 ⇒ 每座房子是一个区间，基站是“刺穿点”。问题变为：用最少的点刺穿所有区间。

一般区间（长度不等）的正确贪心——课件留作练习，期中 Q1 直接考

按右端点排序；结束最早的区间必须被刺中，刺在它的右端点最好（能顺带刺中尽可能多后面的区间）；删去所有被刺中的区间，重复。

错误想法：“刺穿区间最多的点”——课件反例显示会多用一个点。

易错

等长区间时“按左端点排序 + 放在左端点+长度”和“按右端点排序”等价；长度不等时必须按右端点，否则一个很长的早开始区间会让你把点放得太靠右，错过一个很短的区间。

6插曲：图类（Graph Classes）

这一节把前面的问题“抽象成图问题”，理解 NP-hard 问题在特殊图上可能变容易。

定义速查
  • 交图（intersection graph）：每个对象一个顶点，两个对象相交就连边。
  • 区间图（interval graph）：可以表示为实数轴上区间的交图。
  • 单位区间图（unit / proper interval graph）：区间长度都为 1。
  • 团 clique：两两相邻的顶点集；独立集 independent set：两两不相邻；“极大 maximal”= 不能再扩充（不同于“最大 maximum”）。
  • 团覆盖 clique cover：把 V 划分成若干团；大小 = 团的个数。
  • 诱导子图 induced subgraph：只删点（及其关联边）；子图：删点也删边。
  • 色数 chromatic number：合法着色所需最少颜色数。
  • 完美图 perfect graph：每个诱导子图的最大团大小 = 色数。
本节要记住的“等价关系”
  • 活动选择 = 区间图上的最大独立集（给定排好序的区间表示时）。
  • 基站问题 = 单位区间刺穿 = 单位区间图上的最小团覆盖（团中的区间有公共点 ⇒ 一个刺穿点覆盖整个团；Helly 性质）。
  • 区间图识别 O(n+m)；区间图有 O(|V|) 个极大团（练习）。
  • 区间图上：3-着色、着色、团、团覆盖、支配集、哈密顿回路、独立集等都是线性/多项式；但 Maximum Cut 在区间图上是 NP-complete，在单位区间图上多项式。
  • 完美图定理（Lovász 1972）：G 完美 ⇔ 补图完美 ⇒ 每个诱导子图的最大独立集 = 团覆盖数。
  • 强完美图定理（2006）：G 完美 ⇔ 不含奇洞（长度 ≥5 的奇诱导环）和奇反洞。练习：区间图是完美图。
  • 输入不在图类里怎么办：更大的图类（circular-arc、chordal、perfect）；k-interval；k-gap；删掉少量顶点使之落入图类。

7最优排序 Optimal Ordering

7.1 磁带存储 I（等概率）

n 个文件长 Li，读第 i 个文件要扫过前面所有文件。期望读取时间

E = (1/n)·Σi(L1+…+Li) = (1/n)·[ nL1 + (n−1)L2 + … + 1·Ln ]

贪心：按长度升序。证明（相邻交换）：若存在相邻 Li > Li+1，交换后只有这两项系数互换，T − T′ = (n−i+1)Li + (n−i)Li+1 − (n−i+1)Li+1 − (n−i)Li = Li − Li+1 > 0，与最优矛盾。

7.2 磁带存储 II（概率 pi）

E = Σk pk(L1+…+Lk)。两个直觉冲突：短的往前、概率大的往前。按 pi/Li 降序（pi=0 放最后）。

关键计算

交换相邻的 k, k+1：只有它们两项变化，E − E′ = Lkpk+1 − Lk+1pk。若 pk/Lk < pk+1/Lk+1，则 Lk+1pk < Lkpk+1，即 E − E′ > 0，交换后严格更好，矛盾。

小例子

文件 A(L=4, p=0.5)、B(L=1, p=0.2)、C(L=2, p=0.3)。比值：A 0.125，B 0.2，C 0.15 ⇒ 顺序 B, C, A。
E = 0.2·1 + 0.3·(1+2) + 0.5·(1+2+4) = 0.2+0.9+3.5 = 4.6。对比按长度升序（B,C,A）相同；按概率降序（A,C,B）：0.5·4+0.3·6+0.2·7 = 5.2，更差。

7.3 最小化最大延迟 Minimising Job Lateness

问题

任务有时长 ti、截止 di，0 时刻都可开始，一次做一个不可中断。延迟 latei = finishi − di（可负）。最小化 maxi latei。

贪心：Earliest Deadline First（按截止时间升序、无空闲）。时长根本不重要。

证明（相邻逆序交换）

先去掉空闲（不增加延迟）。逆序：i 在 j 前但 dj < di。未排序 ⇒ 有相邻逆序 k, k+1。设这对任务在时刻 C 结束（交换前后相同）。交换前两者最大延迟为 C − dk+1（k+1 后完成且截止更早）。交换后：late′k+1 = C − tk − dk+1 < C − dk+1，late′k = C − dk < C − dk+1。其他任务不变 ⇒ 最大延迟不增加。反复交换得到 EDF 顺序，故 EDF 最优。∎

小例子

任务 (t, d)：J1(3, 6)、J2(2, 8)、J3(1, 9)、J4(4, 9)。EDF：J1→J2→J3→J4，完成 3,5,6,10；延迟 −3,−3,−3,1 ⇒ 最大 1。“最短先做”为什么不行？反例：K1(t=3, d=3)、K2(t=1, d=10)。EDF 先 K1 再 K2：完成 3, 4，延迟 0, −6 ⇒ 最大 0；最短优先先 K2 再 K1：完成 1, 4，延迟 −9, 1 ⇒ 最大 1，更差。

8最优合并与 Huffman 编码

数组合并（练习）

n 个有序数组，每次合并两个（代价 = 两者长度和），直到剩一个。最少移动次数：每次合并当前最短的两个（与 Huffman 同构：合并树中每个元素被移动的次数 = 它所在叶子的深度）。

前缀码

变长编码可能有歧义：a=010, c=101, e=00, k=111, s=100, t=11，“cake” 编码为 10101011100，但它也能解码成 “cats”——因为 t=11 是 k=111 的前缀。

前缀码 prefix code

任何码字都不是另一个码字的前缀 ⇒ 一定可唯一解码。用二叉树表示（左 0 右 1），码字都在叶子上。目标：最小化平均码长 Σ fi·len(Ci)。

Huffman 算法

优先队列存所有符号（按频率）。重复：取出频率最小的两个 x, y，新建符号 xy（频率 fx+fy，左孩子 x、右孩子 y）放回。剩一个时，从根到叶读出码字。O(n log n)。

Huffman 最优性证明三步（考点）
  1. 满二叉树：存在最优前缀码其树每个内部节点都有 2 个孩子（单孩子节点可用孩子替换，码长只减不增）。
  2. 最深兄弟：存在最优树，其中频率最小的两个符号 x, y 是最大深度上的兄弟（交换论证：把低频符号往下换、高频的往上换，期望长度不增）。
  3. 收缩 + 归纳：把 x, y 合并为 xy（频率 fx+fy），得到 n−1 个符号的问题；归纳假设 Huffman 在其上最优；展开 xy 时两棵树都恰好增加 fx+fy，所以 Huffman 仍不差。

9图结构：海啸预警、强连通分量、拓扑排序

海啸预警 Tsunami Warning

n 个塔，坐标 (xi,yi)、半径 ri。激活的塔会激活其半径内的塔（连锁）。最少装几个传感器能激活全部？

错误尝试：只看半径最大；只看直接覆盖最多。都忽略了间接激活。正确建模：有向图 u → v ⇔ v 在 u 的半径内（注意是有向的，半径不同）。

关键观察
  • 互相可达的一组塔（强连通分量 SCC）可看作一个“超级塔”：最多放一个传感器，放哪都一样。
  • 凝聚图（condensation） ΣG：每个 SCC 缩成一点，保留不同 SCC 间的边（去重）。它一定是 DAG（若有环，环上 SCC 可合并成更大的强连通集，矛盾）。
  • 答案 = 凝聚图中入度为 0 的点数。下界：入度 0 的 SCC 无法被别人激活，必须各放一个；上界：任一 SCC 沿入边一直倒退，因无环，必终止于某个入度 0 的 SCC，其传感器会沿路径激活它。

Tarjan 规则（课件原样）
  • 首次访问 v：LOW[v] = ID[v]，v 入 SCC 栈并标记 in-stack。
  • 对边 (u,v)：v 未访问 → 递归，返回后 LOW[u] ← min(LOW[u], LOW[v])；v 已访问且仍在 SCC 栈中 → LOW[u] ← min(LOW[u], ID[v])（包括回边与指向栈中顶点的横叉边）；v 已归属某 SCC → 忽略。

拓扑排序（Kahn 算法）

DAG 的拓扑序：双射 σ: V → {1..n}，边 (v,w) ⇒ σ(v) < σ(w)。每个 DAG 都有（可能多个）。算法：维护入度数组 D 和入度为 0 的集合 S；不断取出 S 中的 u 追加到序列 L，删除其出边并更新入度，入度变 0 就加入 S。最终仍有边 ⇒ 有环。O(|V|+|E|)。

海啸问题的贪心视角：每次选当前剩余凝聚图的一个“源点”（拓扑序第一个）放传感器，删去它能到达的所有分量，重复。

考点

遇到 DAG 题，先拓扑排序再想问题；遇到一般有向图，先缩 SCC 变 DAG。DAG 上最长路、路径计数等都可以按拓扑序 DP。

10单源最短路：Dijkstra

设定

有向图、非负边权、单一源点 s（假设都可达）。无向图把每条边换成两条反向有向边即可。最短路不一定唯一。

算法：维护已确定集合 S；ds=0，其余 ∞。每轮选 V∖S 中 dv 最小的 v 加入 S，对每条出边 (v,z) 松弛：若 dz > dv + w(v,z) 则更新。dv 的含义：中间点都在 S 中的最短路长度。

正确性（必考证明）

设 v 是下一个加入 S 的点，dv 是“只经过 S 的最短路” p 的长度。若存在更短的路 p′，p′ 必在某处第一次离开 S 到达点 y ∉ S。p′ 到 y 的前缀只经过 S，长度 ≥ dy；边权非负 ⇒ len(p′) ≥ dy。而 v 是 S 外 d 最小的，dv ≤ dy ≤ len(p′)，矛盾。∎

更新的完整性：加入 v 后若 dz 变小，新最短路的倒数第二个点一定是 v。否则形如 s→…→v→…→u→z，u 比 v 早进 S，存在不经过 v 的到 u 的最短路 p′，拼上 uz 不比 p 长，且早已是 dz 的候选，矛盾。

数据结构与复杂度

实现找最小更新总时间适用
数组 + 线性扫描O(n) × n 次O(1) × m 次O(n²+m) = O(n²)稠密图 m=Θ(n²) 时线性
增强堆（augmented heap）O(log n) 删除O(log n) 上浮O((n+m) log n) = O(m log n)稀疏图（如道路 m=O(n)）

增强堆：堆数组 A[j] = (i, di)，再加位置数组 P[i] = j，使得能 O(1) 找到顶点 i 在堆中的位置；每次交换两个堆元素时同步更新 P。d 只减少，所以只需上浮（bubble up）。

易错
  • 负权边 Dijkstra 不成立（证明里“后半段不会变短”失效）。
  • O(m + n log n) 需要 Fibonacci 堆，课程规定不能直接引用。
  • m ≥ n−1（全部可达）才能把 O((n+m)log n) 化简为 O(m log n)。

课件前沿注记：Duan 等人 2025 年给出 O(m log2/3 n) 的确定性算法，在稀疏图上首次打破 Dijkstra 界；这属于扩展阅读。

11拟阵 Matroids：贪心一定最优的框架

定义

拟阵 (S, 𝒥)：有限地集 S，𝒥 是 S 的一族子集（称为独立集），满足

  1. 非空：∅ ∈ 𝒥；
  2. 遗传性（hereditary）：X ∈ 𝒥, Y ⊆ X ⇒ Y ∈ 𝒥；
  3. 交换性（exchange）：X, Y ∈ 𝒥 且 |X| > |Y| ⇒ 存在 x ∈ X∖Y 使 Y ∪ {x} ∈ 𝒥。

基（basis）：极大独立集。由交换性，所有基大小相同。

常见拟阵（考试清单里的四个 + 线性拟阵）

图拟阵 / 环拟阵 Cycle (graphic)边集 E边集无环（森林）生成森林（连通时为生成树）

按权重降序排序 s1, s2, ..., sn

时间 O(n log n + n·f(n))，f(n) 为一次独立性查询的时间。输出是基：若被跳过的元素最后还能加入，由遗传性它当时也能加入，矛盾。

正确性证明（交换性的典型用法，考点）

设 G = {g1,…,gk}（贪心）与最优基 H = {h1,…,hk} 都按权重降序。假设 w(G) < w(H)，取第一个 w(gr) < w(hr) 的下标 r。对 Gr−1 = {g1..r−1} 与 Hr = {h1..r} 用交换性：存在 h ∈ Hr∖Gr−1，Gr−1 ∪ {h} ∈ 𝒥。而 w(h) ≥ w(hr) > w(gr)，贪心在处理 gr 之前已遇到 h，且当时（由遗传性）可加入——贪心不会跳过它，矛盾。∎

  • 最小权基：按升序贪心，或令 w′(s) = M − w(s)。
  • 练习：若权重互不相同，最大权基唯一。
  • 权重非负时，最大权基也是所有独立集中权重最大的（任何独立集可扩充为基，权重不减）。
考点（期中 Q3 / Q4 即此）
  • 证明某集合系统是拟阵：逐条验证三条公理，最难的是交换性。
  • 证明不是拟阵：给出具体 X, Y 违反交换性（或违反遗传性）。
  • 把约束识别成“划分拟阵 ∩ 均匀拟阵”等结构，然后直接套贪心定理。
  • 两个拟阵的交一般不是拟阵（如二分图匹配 = 两个划分拟阵的交）。

12最小生成树、Kruskal、并查集与 k-聚类

环拟阵是拟阵

非空、遗传显然（删边不会产生环）。交换性：无环图 (V,F) 有 |V|−|F| 个连通分量。若 |F1| > |F2|，则 (V,F1) 分量更少，必有 F1 中某条边连接 (V,F2) 的两个不同分量，加入 F2 不成环。连通图中，基 = 生成树。故 MST = 环拟阵的最小权基 ⇒ Kruskal 正确。

并查集 Union-Find（size 启发式）

  • 每个集合是一棵有根树，Find 返回根；parent 数组，根无父亲。
  • Union(a,b)：找两个根 c, d；相同则不做；否则把小树的根挂到大树的根下，更新新根的 size。
  • 高度 ≤ log₂ n：v 一旦有父亲 w，挂上去时 size(w) ≥ size(v)，挂完后 size(w) ≥ 2·size(v)，且 v 的子树以后不再变。沿叶到根的 h 条父边，子树大小每步至少翻倍 ⇒ 2h ≤ n。
  • Find、Union 都是 O(log n)。（rank 启发式与之等价；路径压缩可进一步降低摊还复杂度，CLRS §19。）

Kruskal 总复杂度：排序 O(m log m) = O(m log n)（简单图 m < n²）；2m 次 Find + (n−1) 次 Union，O((m+n) log n)；连通 ⇒ O(m log n)。

小观察（期中 Q4 用到）

Kruskal 若把所有边都处理完，被拒绝的边恰好是所有非树边；第一条被拒绝的边就是权最小的非树边。

k-聚类最大间隔 k-clustering of maximum spacing

完全图、边权为距离，把顶点分成 k 个非空簇，使不同簇间最小距离（spacing）最大。

算法：跑 Kruskal，剩 k 个连通分量时停止（即删掉 MST 中最重的 k−1 条边）。

证明

令 δ 为连接两个最终分量的最小边权（我们的 spacing）。这样的边从未被拒绝过（端点一直在不同分量），所以停止时仍未处理 ⇒ 所有已选边权 ≤ δ。任取另一种聚类，必有一对 x, y 在我们这里同簇、在那里异簇；我们的森林中 x 到 y 的路径上每条边 ≤ δ，这条路径必在某条边 (z,w) 处跨越对方的簇边界 ⇒ 对方 spacing ≤ w(z,w) ≤ δ。∎ 时间：排序 Θ(n²) 条边 ⇒ O(n² log n)。

14Module 3 开篇：多项式时间与“输入长度”

多项式时间

算法在每个输入上都在 T(n) = O(nc) 步内结束，c 是固定常数，n 是输入长度（编码的比特数）。指数不能随输入增长。

例 1：最长上升子序列的穷举

[4,1,3] 的每个元素选或不选 ⇒ 2n 个候选，每个检查 O(n) ⇒ O(n·2n)。注意：这只说明这个穷举算法慢，并不说明问题难（LIS 其实有多项式 DP 算法）。

例 2：试除法判素数——为什么 O(√x) 不是多项式

只需试 2..⌊√x⌋（若 x=ab，必有一个因子 ≤ √x）。但输入 x 只占 b = ⌊log₂x⌋+1 位，√x ≈ 2b/2，对 b 是指数的。数值问题里“多项式”指对 log x 多项式。（这也是 SubsetSum 的 O(nt) DP 只是“伪多项式”的原因。）

易错

分析含数字的算法时，问自己“输入有多少位”。O(t) 当 t 以二进制给出时是指数的。

15判定问题、P、NP 与证书

核心定义
  • 判定问题：对每个输入回答 YES/NO。例：“是否有长度 ≥ k 的上升子序列？”
  • P：存在确定性多项式时间算法，对所有输入（YES 与 NO）都答对。
  • NP：存在多项式 p 和问题 B ∈ P，使得对所有 x：
    A(x) = YES ⇔ ∃y: |y| ≤ p(|x|) 且 B(x, y) = YES。
    y 叫证书（certificate），B 的算法叫验证器（verifier / certifier）。
  • YES 实例：至少一个短证书被接受；NO 实例：所有证书都被拒绝。
  • NP = Non-deterministic Polynomial time。它保证验证快，不提供找证书的方法。
问题证书验证
合数 Composite因子 y（1<y<x）检查 x mod y = 0，位数 O(log x)
SAT每个变量一个真值逐个子句检查
Clique (G,k)顶点集 C（位向量）|C|=k 且检查 C(k,2) 对相邻

要点
  • P ⊆ NP：能解就能验证（自己解一遍，不需要证书）。
  • 属于 NP ≠ 难：素数判定在 NP，也在 P（AKS 2002）。
  • P vs NP 未解决；普遍猜想 P ≠ NP。
  • SAT：CNF 公式（子句 = 文字的 OR，子句之间 AND）是否可满足。验证容易；有 2n 种赋值，但多项式算法未必需要逐个尝试——只是没人找到。

16归约 Reductions：方向是一切

Karp 归约（多项式时间多一归约）U ≤P V

存在多项式时间可计算的 f，把 U 的每个实例 x 映射为 V 的实例 f(x)，且 U(x) = YES ⇔ V(f(x)) = YES。输出长度自动是多项式的（写输出也要花时间）。

最常见的错误（考试大扣分点）
  • 方向反了：把新问题 V 归约到 3SAT，只说明 V 不比 3SAT 难，证明不了任何难度。
  • 只证一个方向：只证明“x YES ⇒ f(x) YES”是不够的，还要“f(x) YES ⇒ x YES”（通常写成逆否：x NO ⇒ f(x) NO，也可以）。
  • 构造依赖答案：f 不能用到“满足赋值/最优解”，它只能看输入本身（构造必须多项式时间）。
  • 没有说明构造是多项式时间（给出顶点数/边数的规模即可）。
归约的小例子
  • “避开同色端点边的最短路” → 删掉这些边，跑普通最短路。
  • 区间图（给出区间表示）：“≤ k 个团覆盖所有点” ⇔ “≤ k 个点刺穿所有区间”。点→团：被同一点刺中的区间构成团；团→点：团中区间有公共点。

17Cook 定理、NP-hard、NP-complete

定义
  • Cook 定理：对每个 U ∈ NP，U ≤P SAT（把验证器的计算编码成公式；课上不证）。
  • NP-hard：每个 NP 问题都能多项式归约到它。不要求它本身在 NP 中。
  • NP-complete = NP-hard ∩ NP。SAT 是 NP-complete。
  • 传递性：若 V 是 NP-hard 且 V ≤P W，则 W 是 NP-hard（复合 g∘f 仍保持答案；时间 P(n) + Q(P(n)) 仍是多项式，因为 |f(x)| ≤ P(n)）。
  • 若任一 NP-complete 问题有多项式算法 ⇒ P = NP。

18SAT → 3SAT（第一个“手工”归约）

kSAT：每个子句恰好 k 个文字（允许重复）。2SAT ∈ P（用 SCC + 拓扑排序线性时间求解）；3SAT 是 NP-complete。简单方向 3SAT ≤ SAT 平凡；我们需要 SAT ≤ 3SAT。

构造：长子句拆成链

原子句 x1 ∨ ¬x2 ∨ ¬x3 ∨ x4 ∨ ¬x5 ∨ x6（6 个文字），引入新变量 q1, q2, q3：

(x1 ∨ ¬x2 ∨ q1) ∧ (¬q1 ∨ ¬x3 ∨ q2) ∧ (¬q2 ∨ x4 ∨ q3) ∧ (¬q3 ∨ ¬x5 ∨ x6)

qj 的含义：“到这里为止原文字都是假的，要求还没满足，传给下一个子句”。

  • ⇒：原子句有真文字。第一个真文字之前的 qj 取真，之后取假，每个新子句都满足。
  • ⇐：若原文字全假，链会强迫 q1=T ⇒ q2=T ⇒ q3=T，最后一个子句 (¬q3 ∨ F ∨ F) 为假。
  • r ≥ 4 个文字 → r−2 个子句、r−3 个新变量；短子句重复文字补齐：(a) ↦ (a∨a∨a)，(a∨b) ↦ (a∨b∨b)。规模线性。

3SAT ∈ NP（赋值即证书）+ NP-hard ⇒ 3SAT 是 NP-complete。以后可以从 3SAT 出发归约到图问题。

19写 NP-complete 证明的标准流程

模板（几乎所有题都这样写）
  1. （若要 NP-complete）证明 W ∈ NP：说清证书是什么、长度多项式、验证器做什么、多少时间。
  2. 选一个已知 NP-hard 问题 V（考试清单里的任意一个），写出它的输入。
  3. 构造：由 V 的实例 x 构造 W 的实例 f(x)，包括参数（如 k 的取值）。最好配小例子/图。
  4. 规模：f(x) 的大小和构造时间是多项式的。
  5. （⇒）x 是 YES ⇒ f(x) 是 YES：从 x 的解构造 f(x) 的解。
  6. （⇐）f(x) 是 YES ⇒ x 是 YES：从 f(x) 的任意解“读回” x 的解（常需要先把解“规范化”，如“不妨设解不含某类顶点”）。
  7. 结论：V ≤P W，W 是 NP-hard（再加第 1 步得 NP-complete）。

旁注：若 V ≤P W 且 W ∈ NP，则 V ∈ NP。所以拿一个已知 NP-complete 问题作起点是合适的。

20四个经典归约（课件全部）

统一示例公式：F = (x1∨¬x2∨x3) ∧ (¬x1∨x2∨x3) ∧ (¬x1∨x2∨¬x3)，满足赋值 x1=0, x2=1, x3=1。

20.1 3SAT ≤ Vertex Cover

  • 变量小件：每个变量 xi 两个相邻点 xi、¬xi（覆盖至少选 1 个）。
  • 子句小件：每个子句一个三角形，每个出现位置一个点（覆盖至少选 2 个）。
  • 连接：三角形里的每个出现点连到同名文字的变量点。
  • k = n + 2m：刚好没有余量。
两个方向

赋值 ⇒ 覆盖：选每对中为真的文字点；每个子句挑一个真文字出现留出，其余 2 个选上。共 n+2m。变量边、三角边被覆盖；连接边：若三角端被选则已覆盖，否则它是真文字的出现，其变量端（真文字）被选。

覆盖 ⇒ 赋值：不相交的小件就需要 n+2m 个点 ⇒ 每对恰 1 个、每个三角形恰 2 个。令“选了 xi”为真。每个三角形有一个未选的出现点，它的连接边必须由变量端覆盖 ⇒ 该文字为真 ⇒ 子句满足。∎ 规模：2n+3m 个点，n+3m+3m 条边。

20.2 3SAT ≤ Clique

每个子句的每个出现建一个点（共 3m 个）。两点连边 ⇔ 来自不同子句且不互为相反文字。问是否有大小 k = m 的团。

两个方向

⇒：每个子句选一个真出现，它们来自不同子句且不会矛盾（同时为真），两两相连，得 m-团。

⇐：团中无两点来自同一子句（组内无边），m 个点 ⇒ 每个子句恰一个；彼此不矛盾 ⇒ 令它们为真（其余变量任意）即满足每个子句。∎ 构造 O(m²)。Clique ∈ NP ⇒ NP-complete。

20.3 Vertex Cover ≤ Clique（补图）

(G, k) ↦ (Ḡ, n−k)。关键事实：S 是 G 的点覆盖 ⇔ V∖S 是 G 的独立集 ⇔ V∖S 是 Ḡ 的团。构造补图 O(n²)；k > n 时输出固定 YES 实例。

小例子

G：边 ab, ad, bc, bd, cd, de（6 条）。{b,d} 覆盖所有边（k=2）。剩下 {a,c,e} 在 G 中两两不相邻 ⇒ 在 Ḡ 中是 3 = n−k 的团。

20.4 3SAT ≤ 3-Colouring

  1. 参照三角形 T, F, B：三种颜色分别命名为 1（真）、0（假）、2（第三色）。
  2. 每个变量：点 xi、¬xi 互连且都连 B ⇒ 它们只能用 0/1 且互异 ⇒ 是一个合法真值。
  3. OR 小件：输入 ℓ1, ℓ2；内部 y1, y2, y3；边 ℓ1y1, ℓ2y2, y1y2, y1y3, y2y3。两输入都为 0 ⇒ y₁, y₂ 只能用 1, 2 ⇒ 输出 y₃ 被迫为 0；至少一个输入为 1 ⇒ 存在使 y₃ = 1 的着色。
  4. 子句小件：两个 OR 串联 (ℓ1,ℓ2)→y3，(y3,ℓ3)→y6；再把 y6 连到 B 和 F ⇒ y6 被迫为 1（真）。每个子句 6 个新点、12 条新边。
两个方向

赋值 ⇒ 着色：T,F,B 着 1,0,2；文字按真值着色；每个子句有真输入，小件可补全（取 y3 = ℓ1 ∨ ℓ2，再补全使 y₆=1）；各子句内部点互不相交，补全可以同时进行。

着色 ⇒ 赋值：用 T,F,B 的颜色命名三色；每对文字取相反真值；每个子句输出颜色为 1，若三个输入都为 0 会迫使输出为 0，矛盾 ⇒ 每个子句满足。∎ 规模：3 + 2n + 6m 点，3 + 3n + 12m 边。

注意措辞：小件不是“确定性的 OR 门”，我们只声称“输入允许的着色存在”。

23应对 NP-hard：放宽哪一条？

理想是“所有输入 + 精确答案 + 多项式时间”。NP-hard 意味着（除非 P=NP）三者不可兼得，可以放宽：

放宽方法例子（Vertex Cover / 其他）
时间精确指数算法：减少重复、降低底数VC O*(1.1996n)；Subset Sum meet-in-the-middle
时间（参数化）FPT：指数只依赖小参数 kVC O*(1.25284k)
最优性近似算法（有保证）VC 2-近似
输入范围特殊结构VC 在二分图、区间图、树上多项式
保证启发式COVER 等，基准测试表现好
建模提醒：MaxSAT

“满足尽可能多的子句”可能违反关键约束（8 个中满足 7 个却不可用）。实际用硬子句（必须满足）+ 软子句（尽量满足）。目标函数要匹配应用。

Meet in the middle：Subset Sum 优化版

给 n 个正整数与目标 S，找和不超过 S 的最大子集和。暴力 O(n·2n)。

  1. 分成两半，各枚举所有子集和，得列表 A、B（各至多 M = 2⌈n/2⌉ 个）。
  2. B 排序。
  3. 对每个 a ∈ A, a ≤ S，二分找 B 中 ≤ S − a 的最大 b，更新最优 a+b。

正确性：最优解拆成 a*, b*，处理 a* 时找到的伙伴 ≥ b*。时间 O(n·2n/2)，空间 O(2n/2)。例：[2,5,6,8]、S=12 ⇒ A={0,2,5,7}，B={0,6,8,14}；a=5 时剩 7，取 6，得 11（最优）。n=60 时从“2000 多年”降到“约一分钟”，但内存成为瓶颈（Schroeppel–Shamir 把空间降到 O*(2n/4)）。量子回溯约 √T，仍是指数。

24近似算法 Approximation

r-近似（r ≥ 1，对每个实例都成立）
  • 最小化：OPT(I) ≤ A(I) ≤ r·OPT(I)（r=2：花费不超过最优的两倍）。
  • 最大化：OPT(I)/r ≤ A(I) ≤ OPT(I)（r=2：至少得到最优的一半）。

套路：构造一个可行解 + 找一个最优值的界（下界/上界）+ 比较。不需要知道 OPT。

24.1 Vertex Cover 的 2-近似（取两端点）

任取一条剩余边，两个端点都选上，删去所有与之相邻的边；重复。等价于：扫描边，若两端都没选则都选。O(|V|+|E|)。

证明

被挑出的 k 条边两两无公共端点（是一个匹配）。任何覆盖必须为每条挑出的边选至少一个端点，且一个点不能覆盖两条挑出的边 ⇒ OPT ≥ k。我们选了 2k ≤ 2·OPT 个点；所有边都在被覆盖后才删除 ⇒ 可行。∎

24.2 LP 松弛与对偶给出下界

原始 LP：分数点覆盖

min Σv xv
s.t. xu + xv ≥ 1（每条边 uv）
xv ≥ 0

OPTLP ≤ OPTVC（整数解也是分数解）。

对偶 LP：边价格

max Σe ye
s.t. Σe∋v ye ≤ 1（每个点 v）
ye ≥ 0

弱对偶：任意可行 y 有 Σ ye ≤ OPTLP ≤ OPTVC。

三角形例子：每点取 1/2 可行，代价 3/2；三个约束相加得 2(xa+xb+xc) ≥ 3 ⇒ OPTLP=3/2，而整数最优是 2。LP 给的是界，不一定是整数解。

“取两端点”算法里，令挑出的匹配边价格为 1、其余为 0，这是可行对偶解（每点至多碰一条匹配边）⇒ |M| ≤ OPTLP ≤ OPTVC ≤ |C| = 2|M|。

24.3 加权 Vertex Cover：原始-对偶 2-近似

“取两端点”在加权时会失败（代价 1 和 1000 的一条边，取两端花 1001，最优 1）。改用边价格：对偶约束变为 Σe∋v ye ≤ wv（点的代价是预算）。

算法
  1. 所有价格 0；代价为 0 的点直接选入 S。
  2. 对每条两端都不在 S 中的边 uv：剩余预算 ru = wu − Σe∋uye，同理 rv；令 yuv += δ = min(ru, rv)。
  3. 预算用尽（tight）的端点加入 S。

一次扫描，O(|V|+|E|) 次算术运算。

例：路径 A–B–C，代价 2, 3, 4

处理 AB：δ = min(2,3) = 2 ⇒ A 用尽，选 A。处理 BC：B 剩 1、C 剩 4，δ=1 ⇒ B 用尽，选 B。结果 {A,B} 代价 5；价格总和 3 是下界；最优是 {B} 代价 3。5 ≤ 2·3 ✓。

保证

价格始终可行（每次增加都在两端预算内）⇒ Σ ye ≤ OPT（任何覆盖都触及每条边，用其预算付账）。选中的点都是 tight 的，且保持 tight（之后只给两端都未选的边加价）。故

Σv∈S wv = Σv∈S Σe∋v ye ≤ 2·Σe ye ≤ 2·OPT

（每条边只有 2 个端点，价格最多被数两次。）所有代价为 1 时就退化为“取两端点”。∎

24.4 0-1 背包的 1/2-近似

单用“密度优先”会失败（物品 1 重 1000 值 1000、物品 2 重 1 值 1.001，容量 1000：密度先拿物品 2 后放不下物品 1）。单用“价值优先”也会失败（一个重 1000 值 1.001 的大件 vs 1000 个重 1 值 1 的小件）。

算法

先丢掉 wi > W 的物品。候选 1：按密度降序取前缀 P，遇到第一个放不下的物品 j 就停；候选 2：价值最大的单件。返回两者中更好的。O(n log n)。

证明

分数背包按密度装满是分数最优（等重量交换：把低密度物品的 δ 重量换成高密度的，价值变化 δ(ρhigh − ρlow) ≥ 0）。分数最优 ≥ 0-1 最优。剩余容量 R < wj：

OPT ≤ VP + (R/wj)·vj ≤ VP + vj ≤ VP + Vsingle

两个数之和 ≥ OPT ⇒ 较大者 ≥ OPT/2。∎ 例：W=10，a(2,6)、b(9,18)、c(6,9)（密度 3,2,1.5）：前缀 {a} 值 6，b 放不下；最大单件 b 值 18 ⇒ 返回 {b}；分数上界 6 + (8/9)·18 = 22。

24.5 Metric TSP 的 2-近似

完全图、非负边长、满足三角不等式 d(i,k) ≤ d(i,j) + d(j,k)。

三步证明
  1. MST 是下界：从最优回路删一条边得到一棵生成路径（树），w(T) ≤ OPT − w(e*) ≤ OPT。
  2. DFS 绕树一圈，每条树边走两次：长度 2w(T) ≤ 2·OPT。
  3. 跳过已访问的点（shortcut）：三角不等式保证不变长。⇒ 可行回路长度 ≤ 2·OPT。

时间：完全图上 Prim + 数组 O(n²)，遍历与捷径 O(n)。

24.6 一般 TSP 不可近似（gap 归约）

定理：除非 P = NP，一般 TSP 不存在任何常数 c 的多项式时间 c-近似。

证明（从 Hamiltonian Cycle 归约）

给 n ≥ 3 个点的图 G，构造完全图 G*：原有边权 1，添加的边权 c·n。

  • G 有哈密顿回路 ⇒ OPT = n ⇒ 近似算法返回 A ≤ c·n。
  • G 无哈密顿回路 ⇒ 每条回路至少用一条重边 ⇒ A ≥ OPT ≥ cn + (n−1) > cn。

所以“A ≤ cn 吗？”就判定了 Hamiltonian Cycle ⇒ P = NP。（G* 不满足三角不等式，所以不与 metric 版本矛盾。）例：c=2, n=4，回路图得 4 ≤ 8，路径图至少 8+1+1+1 = 11 > 8。

问题证明用的界保证
加权 Vertex Cover下界：可行边价格（对偶）≤ 2·OPT
0-1 背包上界：分数最优≥ OPT/2
Metric TSP下界：MST≤ 2·OPT
一般 TSP—无常数近似（除非 P=NP）

25超越 NP：coNP、多项式层级、计数

25.1 coNP

  • 补问题 coA：答案取反。A ∈ coNP ⇔ coA ∈ NP。coP = P。
  • 两种等价视角（B 为多项式检查）：A(x)=NO ⇔ ∃y: B(x,y)=0（短 NO-证书 / 反例）；A(x)=YES ⇔ ∀y: B(x,y)=1。
  • coNP-complete 例：Tautology（每个赋值都真？反例一个赋值）、Not-3-Colourable（NO 证书：一个 3-着色）、Is-Min-Vertex-Cover（给定覆盖 S 是最小的吗？NO 证书：更小的覆盖 T）。
  • 例：Expansion（每个 |S| ≤ |V|/2 的集合是否满足 |N(S)| ≥ |S|）在 coNP：违反的 S 就是 NO 证书。

25.2 量词与多项式层级 PH

量词顺序很重要：∃y ∀z: y = z 为假（先选 y 无法应对所有 z）；∀z ∃y: y = z 为真。

  • Oracle：假想的子程序，一步回答某个判定问题（如 SAT）。多项式算法可问多项式次，后面的询问可依赖前面的答案。
  • PSPACE：多项式空间可解。可以逐个尝试赋值、重用空间，因此 PH ⊆ PSPACE（时间可能指数）。

25.3 计数：#P、FP、Cook 归约

  • FP：多项式时间可计算的函数（输出不只是 YES/NO）。
  • #P：形如 A(x) = |{y ∈ {0,1}p(|x|) : B(x,y)=1}| 的函数（数被接受的证书个数）。例：#SAT。
  • Cook 归约（多项式时间图灵归约） A ≤TP B：用 B 的 oracle 在多项式时间内解 A，可以多次询问、适应性询问。例：SAT ≤ #SAT（问个数是否 > 0）。
  • #P-hard：每个 #P 函数都能用它的 oracle 多项式计算；#P-complete = 在 #P 中 + #P-hard。#SAT 是 #P-complete。
  • 判定容易 ≠ 计数容易：二分图找一个完美匹配是多项式的，计数完美匹配是 #P-complete。
  • Parsimonious 归约：保持解的个数（一一对应）。课件练习：SAT ≤ 3SAT 的链式构造不是 parsimonious（原赋值可能有多种 q 的扩展），如何让扩展唯一 ⇒ 证明 #3SAT 是 #P-complete。（提示：让 qj 被前面的文字唯一确定，例如额外加子句强制 qj ⇔ (前面文字都假)。）

26线性规划 Linear Programming

26.1 建模：沙拉问题

做 300g 沙拉，风味 ≥ 7、口感 ≥ 7，成本最小。变量 xL, xT, xO ≥ 0（单位 100g，可取分数）：

min xL + 0.8xT + 0.6xO　s.t.　xL+xT+xO = 3,　4xT+xO ≥ 7,　6xL+2xO ≥ 7

可行解 (1.1, 1.7, 0.2) 代价 $2.58，是最优（等成本线在可行三角形上的最后一点）。LP 的三种结局：有最优解、不可行、无界。求解：单纯形法（实践快，最坏指数）、椭球法/内点法（多项式，按二进制输入长度计）。

26.2 整数规划与 LP 松弛

  • ILP：变量必须是整数。一般 ILP（即使只判可行性）是 NP-complete（如从 Vertex Cover 归约）；整数点少 ≠ 更容易。
  • 沙拉 II（整包 100g）：风味 ≥ 7 需至少 2 包番茄，剩下至多 1 包，口感 ≤ 6 < 7 ⇒ 无可行整数解，而 LP 有解。
  • LP 松弛：去掉整数约束，可行集变大 ⇒ 最小化时 LP 最优 ≤ 整数最优（例：至少 150g、100g 一包：整数 2 包 $2，分数 1.5 包 $1.5）。
  • 背包 ILP：max Σ vixi, Σ wixi ≤ W, xi ∈ ℤ≥0；0-1 背包再加 xi ≤ 1（练习答案）。

26.3 对偶：用约束的非负组合证明上界

原始 P

max 3x1+x2+2x3
x1+x2+3x3 ≤ 30
2x1+2x2+5x3 ≤ 24
4x1+x2+2x3 ≤ 36
x ≥ 0

对偶 P*

min 30y1+24y2+36y3
y1+2y2+4y3 ≥ 3
y1+2y2+y3 ≥ 1
3y1+5y2+2y3 ≥ 2
y ≥ 0

(8,4,0) 可行、值 28 ⇒ OPT ≥ 28。行权重 (1,1,0) 给上界 54；行权重 (0, 1/6, 2/3) 给上界 4+24 = 28 ⇒ OPT = 28，(8,4,0) 最优。寻找最好的行权重本身就是对偶 LP。

对偶的公式与定理
  • 标准形：max cTx, Ax ≤ b, x ≥ 0 的对偶是 min bTy, ATy ≥ c, y ≥ 0（每条约束一个对偶变量，矩阵转置）。对偶的对偶是原问题。
  • 弱对偶：cTx ≤ yTAx ≤ bTy（需要 x ≥ 0 和 y ≥ 0 保持不等号方向）。最大化原问题：原可行值 ≤ OPT ≤ 对偶可行值；最小化原问题方向相反。
  • 强对偶：原问题可行且有有限最优 ⇒ 对偶最优值相等（不证）。
  • 求解器返回原、对偶解，检查可行性与值：L = U 则都最优；否则 [L, U] 包住 OPT。验证不需重跑求解器。

26.5 分离预言机 Separation Oracle

约束太多写不下（如“任意子集的和 ≤ 1”有 2n 条）：只需一个过程，给点 x，要么确认可行，要么返回一条 x 违反但所有可行点满足的线性不等式。例中：把所有正坐标加起来，≤ 1 则全部满足，否则这些下标就是被违反的约束。椭球法：变量数多项式 + 高效分离 ⇒ 多项式时间优化。注意：它处理“很多约束”，不自动处理“很多变量”（可以考虑对偶）。
