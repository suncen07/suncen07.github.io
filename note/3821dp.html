动态规划（Dynamic Programming）核心知识点精讲

依据课程讲义 4-dp-short 整理：计数 → 状态设计 → 双参数（背包、字符串）→ 区间划分 → 图上路径 → 子集 DP → 方法总结，外加选读的字符串匹配（Rabin–Karp、KMP）。每节都有可以手算的小例子和考点提示。

先记住：一个完整的 DP 解答必须交代的 6 件事（课件 §1 末尾，几乎就是评分标准）
  1. 状态 State：一个表项到底回答什么问题？（用一句完整的话写清楚，包括每个参数的含义）
  2. 递推 Recurrence：依赖哪些更小的答案？为什么这些情况覆盖了所有解？
  3. 边界 Base cases：从哪里开始？空集、不可能（∞）的情况怎么处理？
  4. 顺序 Order：计算某项时，它依赖的项是否都已算好？
  5. 答案 Result：哪一项（或哪些项的组合）是原问题的答案？
  6. 代价 Cost：状态数 × 每个状态的工作量；空间。若要输出具体解，还要说明如何记录选择并回溯。

与贪心的区别：贪心“只做一个选择并证明它安全”；DP“比较所有选择，但相同的子问题只算一次”。

1复用子问题的答案：计数入门

1.1 跳房子 Hopscotch：数路线

从格 0 出发，每次走 1 格（step）或 2 格（jump），恰好到达格 n 的走法有多少？顺序不同算不同路线。

按“最后一步”分类

状态：N(i) = 到格 i 的路线数。每条到 i 的路线最后一步要么是 step（前面是到 i−1 的路线），要么是 jump（前面是到 i−2 的路线），两类不重不漏：

N(0) = 1,　N(1) = 1,　N(i) = N(i−1) + N(i−2)　(i ≥ 2)

N(0)=1：空的走法也算一种（易错！）。表：1, 1, 2, 3, 5, 8 ⇒ 到格 5 有 8 种。

自底向上 Bottom-up（填表）
N[0] = 1; if n >= 1: N[1] = 1
for i = 2..n: N[i] = N[i-1] + N[i-2]
return N[n]
自顶向下 Top-down（记忆化 memoisation）
count(i):
  if i <= 1: return 1
  if i not in memo:
     memo[i] = count(i-1) + count(i-2)
  return memo[i]

正确性 = 按填表顺序做归纳：基础项正确；假设前面的项都对，按最后一步把路线分成两组，去掉最后一步得到到 i−1 或 i−2 的路线，反之加上最后一步也合法，两组不相交且穷尽 ⇒ 计数相加。

“算术操作数”≠“比特复杂度”

O(n) 个状态 × 1 次加法 = O(n) 次算术运算；只留最后两个数则 O(1) 个存储数。但 N(n) = Fn+1 = Θ(φn) 有 Θ(n) 位，第 i 次加法花 O(i) 位运算 ⇒ 总比特代价 O(n²)。考试题如果答案会变得很大，要意识到这个区别。

1.2 汉诺塔 Tower of Hanoi：最少步数

最大盘把过程分成三段：小的 n−1 个从 A 移到 B → 最大盘 A→C → 小的从 B 移到 C。

最优性（下界 + 匹配构造）

最大盘第一次移动前，小的 n−1 个必须全部移开：≥ M(n−1) 步；最大盘最后一次到 C 后，小的必须全部移到它上面：≥ M(n−1) 步；最大盘至少移动 1 次。故 M(n) ≥ 2M(n−1)+1，三段策略恰好达到。M(0)=0 ⇒ M(n) = 2n − 1（0,1,3,7,15,31）。

复用的是“次数”不是“移动序列”：两次子转移的盘子在不同柱子之间，移动列表不同，但次数相同。答案很大 ≠ 输出很长：输出 2n−1 这个数只要 n 位；而列出所有移动必须 2n−1 步，任何复用都省不掉。

状态设计是最核心的决定

检验法：两个部分解如果状态相同，能不能用同一条规则继续扩展它们？不能 ⇒ 状态漏记了重要信息。记得太少：递推无法证明；记得太多：状态数爆炸。

2选择状态记住什么：单参数 DP

2.1 最长上升子序列 LIS

“前缀里最长的长度”不够——不知道末尾值，就不知道下一个数能否接上（[1,5] 和 [1,3] 都长 2，但 4 只能接在后者后面）。固定终点：

状态与递推

L[i] = 以 A[i] 结尾的最长严格上升子序列长度。

L[i] = 1 + max( {0} ∪ { L[j] : j < i, A[j] < A[i] } )

按 i 递增计算；答案 maxi L[i]（不一定以最后一个元素结尾！空输入答 0）。O(n²) 时间、O(n) 空间。

A[i]15362748
L[i]12232435
p[i]01121436

回溯：同时存前驱 p[i]（达到最大值的 j，没有则 0）。从 L 最大的 8 出发：8→6→4→2→1，反转得 1, 5, 6, 7, 8。例：L[7]（值 4）只能接在值 1、3、2 后面，位置 6（值 7）虽然更长但不能接。

课件练习：O(n log n) 解法

提示的意思：同样长度的上升子序列中，末尾值越小越好（更容易被延长）。维护数组 tail[ℓ] = 所有长度为 ℓ 的上升子序列中最小的末尾值；它是严格递增的。对每个新值 x，二分找第一个 tail[ℓ] ≥ x 并替换为 x（找不到就追加）。最终数组长度即答案。

上例：1 → [1]；5 → [1,5]；3 → [1,3]；6 → [1,3,6]；2 → [1,2,6]；7 → [1,2,6,7]；4 → [1,2,4,7]；8 → [1,2,4,7,8]，长度 5 ✓。（注意 tail 本身不一定是一个真实的子序列。）

2.2 带权活动选择：最大化总时长

贪心模块里“最早结束”最大化的是个数；改为最大化总时长时贪心失败（两个短活动 vs 一个长活动）。

状态与递推

按结束时间排序 f1 ≤ … ≤ fn。T[i] = 以活动 i 作为最后一个的相容方案的最大总时长（最后一个活动的结束时间决定下一个能否放下）。

T[i] = (fi − si) + max( {0} ∪ { T[j] : j < i, fj ≤ si } )

答案 maxi T[i]。排序 O(n log n) + 每个状态至多查 n 个前驱 ⇒ O(n²)。

例（一组与课件表格数值一致的区间）

活动 1 [0,2)、2 [1,5)、3 [2,6)、4 [5,8)、5 [6,9)：T = 2, 4, 2+4=6, 3+max{2,4}=7, 3+max{2,4,6}=9；p = 0,0,1,2,3。回溯 5→3→1 ⇒ 选 {1,3,5}，总时长 9。

正确性要点：最优方案的前驱为 j，则前面的部分在 fj 结束；把它换成以 j 结尾的更好的方案，结束时间仍是 fj，仍与 i 相容，总值更大——矛盾。所以最优解由最优子解组成（最优子结构）。

更快的做法（课件未要求）：若定义 D[i] = 只用前 i 个活动的最优值，则 D[i] = max(D[i−1], (fi−si) + D[q(i)])，q(i) 用二分求得，总 O(n log n)。

2.3 找零 Making Change：最少硬币数

面额 v1 < … < vn，每种无限，凑出恰好 C。贪心（先拿最大）在 {1,3,4}、C=6 时得 4+1+1（3 枚），最优是 3+3（2 枚）。

状态与递推

M[a] = 恰好凑出 a 的最少硬币数。M[0] = 0；

M[a] = 1 + mink: vk ≤ a M[a − vk]

凑不出时记 +∞（约定 min ∅ = ∞，1+∞ = ∞）。按 a = 0..C 计算，答案 M[C]（为 ∞ 则报告无解）。

M[6] = 1 + min{M[5], M[3], M[2]} = 1 + 1 = 2，回溯：存 p[a] = 达到最小值的面额，6 →(3)→ 3 →(3)→ 0。

伪多项式（重点考点）

时间 O(nC)、空间 O(C)。C 在输入里只占 ⌊log₂C⌋+1 位，但我们为 0..C 每个数都建了状态（C=1000 只需 10 位却要 1001 个表项）。对数值 C 多项式 ≠ 对输入长度多项式。这和 Module 3 里 SubsetSum/Knapsack 是 NP-hard 并不矛盾。

2.4 无限背包 Integer Knapsack（每种物品可拿多件）

状态与递推

B[c] = 总重至多 c 的最大价值。B[0] = 0；

B[c] = max( {0} ∪ { vk + B[c − wk] : wk ≤ c } )

“0” = 空背包，也处理了“放不下任何物品”。因为可无限拿，去掉一件后所有物品仍可用 ⇒ 一个参数够。

3双参数：资源与字符串

3.1 0-1 背包

为什么一维会错

只有物品 A(重 2, 值 3)：容量 2 的最优值 3；用一维递推算容量 4 会得到“再加一个 A”= 6，实际仍是 3。存一个最优方案也不够：要加的物品可能已在方案里，而有用的可能是另一个（甚至更差的）方案。

状态与递推

K(k, c) = 只用物品 1..k、总重 ≤ c 的最大价值。对第 k 件物品：不拿 或 拿一次，两种情况都只再用前 k−1 件：

K(k,c) = K(k−1,c)　若 wk > c；　否则 max{ K(k−1,c), vk + K(k−1, c−wk) }

边界 K(0,c) = 0、K(k,0) = 0；答案 K(n,C)。逐行填（所有依赖都在上一行）。

3.2 平衡划分 Balanced Partition（归约到背包）

把正整数分成两组使和的差最小。总和 T，较小组 B 满足 SB ≤ T/2，差 = T − 2SB ⇒ 让 SB 尽量大但不超过 ⌊T/2⌋。每个数 xi 变成物品 wi = vi = xi，容量 ⌊T/2⌋；最优值 s ⇒ 最小差 T − 2s。O(nT)。例：{2,3,4,6}，T=15，容量 7，最优 3+4=7，差 1。

3.3 最长公共子序列 LCS

状态与递推

L(i,j) = A[1..i] 与 B[1..j] 的 LCS 长度。

L(i,j) = 1 + L(i−1,j−1)　若 ai = bj；　否则 max{ L(i−1,j), L(i,j−1) }

边界 L(0,j) = L(i,0) = 0；逐行、行内 j 递增；答案 L(n,m)。

两个关键论证
  • 末字符相等可直接匹配：若最优解用了其中一个末位置，把它改为与另一个末位置匹配；若都没用，可以把这个公共字符追加上去变得更长。所以存在最优解匹配两端。
  • 末字符不等：两个末位置不可能都被用（它们只能彼此匹配）⇒ 至少丢掉一个，两种情况取最大。

三个串的 LCS：两两求解会丢信息

A=abcdegg、B=acbeefg、C=accedgf。abeg 与 aceg 都是 A,B 的 LCS；若选 abeg 再与 C 求，只得 aeg（3）；而 aceg 也是 C 的子序列（4）。正确做法：三维状态 L(i,j,k)，三个末字符全相等时 1+L(i−1,j−1,k−1)，否则在去掉某一个末字符的三种情况中取最大。O(nmℓ)。

3.4 最短公共超序列 SCS

包含两个串作为子序列的最短串。用 LCS 共享尽可能多的字符：长度 = n + m − L。下界：任何公共超序列中，被两个串同时使用的位置构成公共子序列，最多 L 个。例：cat 与 cot，LCS = ct，得 coat 或 caot（长 4 = 3+3−2）。

3.5 编辑距离 Edit Distance

状态与递推

操作：插入 cI、删除 cD、替换 cR。E(i,j) = 把 A[1..i] 变成 B[1..j] 的最小代价。按“最后一步”分三类：

E(i,j) = min{ E(i−1,j) + cD,　E(i,j−1) + cI,　E(i−1,j−1) + r(ai,bj) }

r(a,b) = 0（相等）或 cR。边界 E(i,0) = i·cD、E(0,j) = j·cI。单位代价时即 Levenshtein 距离。

4选择分割点：区间 DP

4.1 矩阵链乘 Matrix Chain Multiplication

a×b 乘 b×c 用 abc 次标量乘法。结合律让括号可变，矩阵顺序不变，代价却可能差 10 倍：A 10×100、B 100×5、C 5×50：(AB)C = 5000 + 2500 = 7500；A(BC) = 25000 + 50000 = 75000。

加括号方式数 T(n) = Σk T(k)T(n−k)：1, 1, 2, 5, 14, 42, …，即 Catalan 数 Cn−1，Cr = (1/(r+1))·binom(2r, r) = Θ(4r/r3/2)，指数增长（同一个数还计数：括号序列、不越过对角线的格路、满二叉树、凸多边形三角剖分、避开 123 模式的排列）。

为什么“前缀”状态不行

前缀 A1…A5 的最后一次乘法若在 A₂ 后分开，右边 A3…A5 是一个区间而不是前缀 ⇒ 状态需要记住两个端点。

状态与递推

Ai 为 pi−1×pi。M[i,j] = 计算 Ai…Aj 的最小代价。枚举最后一次乘法的位置 k：

M[i,i] = 0,　M[i,j] = mini ≤ k < j ( M[i,k] + M[k+1,j] + pi−1·pk·pj )

关键：子积的形状只由端点决定（pi−1×pk 与 pk×pj），与它内部怎么加括号无关。按区间长度 1, 2, …, n 递增计算；答案 M[1,n]。

例：A 10×100、B 100×5、C 5×50（p = 10, 100, 5, 50）

M[1,2] = 10·100·5 = 5000，M[2,3] = 100·5·50 = 25000；

M[1,3] = min{ M[1,1]+M[2,3]+10·100·50 = 75000,　M[1,2]+M[3,3]+10·5·50 = 7500 } = 7500，存分割 K[1,3] = 2 ⇒ (AB)C。

回溯括号：在 [i,j] 处递归打印 [i, K[i,j]] 与 [K[i,j]+1, j]，外加一对括号；i = j 时停。

正确性与复杂度

取 Ai…Aj 的最优加括号及其最后分割 k：若某一侧有更便宜的加括号，替换后乘积和形状都不变而总代价更小——矛盾。所以两侧都最优；反之每个候选都是合法的加括号。按区间长度归纳。

O(n²) 个区间 × 每个至多 n 个分割 ⇒ O(n³) 时间，O(n²) 空间。

课件练习“能否更细地分析成 o(n³)？”——不能：长度 ℓ 的区间有 n−ℓ+1 个，各试 ℓ−1 个分割，总数 Σℓ(n−ℓ+1)(ℓ−1) = (n³−n)/6 = Θ(n³)（例如仅长度在 n/3 到 2n/3 的区间就贡献 Ω(n)·Ω(n)·Ω(n)）。

4.2 表达式加括号求最大值（含课件练习完整答案）

数 a1,…,an 和固定运算符 ∘1,…,∘n−1 ∈ {+, −, ×}，加括号使值最大。与矩阵链不同：括号会改变结果本身。例：10 − ((1−2)−3) = 14，10 − (1−(2−3)) = 8。

只存最大值不够
  • 减法：要使 X − Y 最大，需要 X 最大、Y 最小。
  • 乘法：两个负数相乘可能最大：两边都是 1−2−3（可为 −4 或 2），只用最大值得 2·2 = 4，漏掉 (−4)(−4) = 16。
完整 DP 解答（按 6 要素写）
  1. 状态：对 1 ≤ i ≤ j ≤ n，L[i,j] / H[i,j] = 子表达式 ai ∘i … ∘j−1 aj 在所有完全加括号方式下能取到的最小 / 最大值。边界 L[i,i] = H[i,i] = ai。
  2. 递推：枚举最后运算 ∘k（i ≤ k < j），左区间 [i,k]、右区间 [k+1,j]。令候选集合
    • ∘k = +：{L[i,k] + L[k+1,j], H[i,k] + H[k+1,j]}
    • ∘k = −：{L[i,k] − H[k+1,j], H[i,k] − L[k+1,j]}
    • ∘k = ×：{x·y : x ∈ {L[i,k], H[i,k]}, y ∈ {L[k+1,j], H[k+1,j]}}（四个组合）
    H[i,j] = 所有 k 的候选的最大值，L[i,j] = 最小值。
  3. 顺序与答案：按区间长度递增；答案 H[1,n]。
  4. 回溯：对每个 (i,j) 和“最大/最小”分别存达到极值的 k 以及左右各取的是 L 还是 H；从 (1,n,max) 递归展开括号。
  5. 正确性：固定最后运算 ∘ₖ 后，左右两侧的值可以独立选择（各自取到其可达值集合中的任意值）。函数 x+y 对两个变量都单调增，x−y 对 x 增、对 y 减，所以极值在端点取到；x·y 对固定 y 是 x 的线性函数（反之亦然），在矩形 [L,H]×[L′,H′] 上的极值必在四个角取到——而四个角都可达（它们本身就是可达的极值），即使中间值不一定可达也没关系。按长度归纳即得。
  6. 复杂度：O(n²) 个区间 × O(n) 个分割 × 常数个候选 ⇒ O(n³) 时间、O(n²) 空间。

5.1 DAG 上的最短（最长）路

拓扑序保证：处理某点时，它所有可能的前驱都已处理。负权边没问题——计算顺序来自图结构，而不是当前距离估计（这正是 Dijkstra 做不到的）。

递推

d(s) = 0，d(t) = min(v,t)∈E (d(v) + w(v,t))（空的 min 为 ∞）。按拓扑序处理，O(n+m)（每条入边扫描一次：入度之和是 m，不是 n²）。最长路：把 min 换成 max，不可达用 −∞，仍 O(n+m)。一般图上最长简单路是 NP-hard：无环性去掉了“要记住访问过哪些点”的需要。

5.2 装配线调度 Assembly Line

两条线，作业 1..n 依次完成。si 进入、fi 离开、ai,k 处理、ti,k 在作业 k 后从线 i 换到另一条线。

F1(k) = a1,k + min{ F1(k−1), F2(k−1) + t2,k−1 }，F2 对称；Fi(1) = si + ai,1；答案 min{F1(n)+f1, F2(n)+f2}

课件例子

进入 (1,2)，离开 (2,1)；处理 线1: 4,2,5；线2: 2,6,2；换线 线1 后: 1,2；线2 后: 2,1。
(F₁,F₂)(1) = (5, 4)；(2) = (2+min{5, 4+2}, 6+min{4, 5+1}) = (7, 10)；(3) = (5+min{7, 10+1}, 2+min{10, 7+2}) = (12, 11)。结束 min{12+2, 11+1} = 12，路线 线1, 线1, 线2。O(n)。

5.3 Bellman–Ford：有环、有负权边

有环时没有拓扑序；有负边时 Dijkstra 的“最小即确定”会错（s→a 4 看似最终，但 s→b→a = 5−3 = 2）。可达的负环会使受影响的点没有有限最短距离（只有从 s 可达、且能从负环到达的点受影响）。

加一个“边数上限”参数，使依赖无环

无可达负环时，存在不重复顶点的最短路（删去非负的环不会变长）⇒ 最多 n−1 条边。

di(v) = 至多用 i 条边的 s→v 走法的最小权。d0(s)=0，其余 ∞；

di(v) = min{ di−1(v), min(u,v)∈E ( di−1(u) + w(u,v) ) }

答案 dn−1(v)。依赖只从第 i−1 层到第 i 层，即使原图有环。

  • 两行实现：每轮复制旧行，对每条边 new[v] ← min(new[v], old[u]+w)；O(n(n+m)) 时间、O(n) 空间；保留所有行（O(n²)）便于回溯（记录“保持”或“追加边 (u,v)”，平局优先“保持”以免绕零权环）。
  • 单数组原地更新（常见写法）：一轮里后面的边可能用到本轮的改进，所以第 i 轮后的值“至少和 ≤ i 条边的最优一样好”；n−1 轮后精确。O(nm + n)。
  • 提前结束：一整轮没变化即可停止。检测负环：n−1 轮后再扫一遍边，若还能严格改进 ⇒ 存在从 s 可达的负环。SPFA（队列优化）最坏仍是 Bellman–Ford 的界。

5.4 Floyd–Warshall：全源最短路

状态与递推

顶点编号 1..n。Dk(i,j) = 从 i 到 j、中间点只允许是 1..k 的最短距离。

Dk(i,j) = min{ Dk−1(i,j), Dk−1(i,k) + Dk−1(k,j) }

D0(i,i) = 0，有边则 w(i,j)（平行边取最小），否则 ∞。为何两段就够：无负环时取最短简单路，若经过 k 则只经过一次，切开后两段中间点都 < k。

课件例子：A→B 4，B→C −2，C→A 3，A→C 10
D₀D₁（允许 A）D₂（再允许 B）D₃（再允许 C）
ABCABCABCABC
A04100410042042
B∞0−2∞0−2∞0−210−2
C3∞0370370370

D₁(C,B) = 3+4 = 7；D₂(A,C) = min{10, 4−2} = 2；D₃(B,A) = −2+3 = 1。

for k = 1..n:          // k 必须在最外层：它决定“允许哪些中间点”
  for i = 1..n:
    for j = 1..n:
      D[i][j] = min(D[i][j], D[i][k] + D[k][j])

时间 O(n³)，空间 O(n²)（单矩阵原地更新是安全的：无负环时 D[k][k]=0，第 k 阶段第 k 行、列不变）。路径恢复：存 next[i][j]（初始直接边为 j；经 k 严格改进时设为 next[i][k]）。

方法“更早”的依赖是什么时间
DAG 路径拓扑序中更早的点O(n+m)
装配线更早的作业O(n)
Bellman–Ford少一条允许的边O(nm+n)
Floyd–Warshall更少的允许中间点O(n³)
设计问题（考点）

如果最自然的递推是循环依赖的，加什么额外限制能让依赖只指向更小的状态？（边数上限、允许的中间点集合、拓扑序……）

6记住一个子集：指数级但比暴力好

有些问题的未来取决于“用过了哪些对象”。状态可以是一个集合——状态数可能是指数级，DP 不一定给出多项式算法，但能把 n! 降到 2ⁿ 级别。

6.1 TSP：Held–Karp 子集 DP

状态与递推

固定起点 s。D(S, v) = 从 s 出发、恰好访问 S 中每个点一次、在 v 结束的最小代价（s, v ∈ S）。访问顺序不是状态的一部分：s→a→b→c 与 s→b→a→c 的后续选择完全一样，只保留更便宜的。

D({s}, s) = 0,　D(S, v) = minu ∈ S∖{v} ( D(S∖{v}, u) + w(u,v) )

缺边记 ∞；D(S, s) = ∞（S ≠ {s}，不能提前回到 s）。按 |S| 递增计算。闭合：tour = minv ≠ s ( D(V, v) + w(v, s) )。

方法记住什么时间空间
枚举回路整个顺序O(n·(n−1)!)O(n)
子集 DP访问集合 + 终点O(n²2ⁿ)（稀疏图 O((n+m)2ⁿ)）O(n2ⁿ)

收益来自合并“未来选择相同”的历史，代价是一张大得多的表。

6.2 图着色：一次拿掉一个颜色类

状态与递推

同色的点构成独立集。C(S) = 诱导子图 G[S] 的色数。

C(∅) = 0,　C(S) = 1 + min∅ ≠ I ⊆ S, I 独立 C(S∖I)

按 |S| 递增；答案 C(V)。例：5-环 a-b-c-d-e-a，取 I = {a,c}，剩 {b,d,e} 只有 d–e 相邻需 2 色 ⇒ 1 + 2 = 3。

复杂度：ΣS 2|S| = Σj binom(n,j) 2j = 3ⁿ（每个点在 (S, I) 中有三种角色：不在 S、在 S∖I、在 I）⇒ O*(3ⁿ) 时间、O*(2ⁿ) 空间。

改进：只枚举极大独立集（Lawler 1976）

极大 ≠ 最大（路径 a–b–c：{b} 极大但 {a,c} 更大）。取最优着色的一个颜色类 I，若外面某点与 I 无邻居，就把它改成 I 的颜色——不产生冲突、不增加颜色；重复直到 I 极大 ⇒ 只需考虑极大独立集。

j 个点的图至多 3j/3 个极大独立集（Moon–Moser），可在 O*(3j/3) 列出 ⇒ Σ binom(n,j)3j/3 = (1+31/3)ⁿ ≈ 2.4423ⁿ。状态和含义不变，只是每个状态的候选更少。（用容斥可到 O*(2ⁿ)，超出本课。）

6.3 二分图上的支配集（Liedloff 2008）

选最少的点，使每个点被选或与被选点相邻。即使在二分图上也是 NP-hard。思路：枚举较小一侧 A 的选择，剩下的用覆盖 DP 补全。

算法
  1. 设 |A| ≤ |B|，B = {b₁..b_q}。覆盖表：H(R, k) = 在 b₁..b_k 中选最少的点，使其邻居覆盖 R ⊆ A。 H(R,k) = min{ H(R,k−1), 1 + H(R ∖ N(bk), k−1) }，H(∅,k)=0，H(R,0)=∞（R≠∅）。
  2. 对每个 X ⊆ A：Y = B ∖ N(X)（被迫选），R = A ∖ (X ∪ N(Y))。
  3. 返回 minX |X| + |Y| + H(R, q)。

正确性：Y 是被迫的；Y 中的点与 R 无邻居，所以残余覆盖不需要重复选 Y 的点。时间 O*(2|A|) ⊆ O*(2n/2)。例：H({a₂,a₃},3) = min{∞, 1 + H({a₃},2)} = 2。

6.4 计数二分图完美匹配

完全二分图有 n! 个完美匹配，列举至少阶乘时间；DP 把“补全方式的个数”相加而不是列举。

状态与递推

M(i, U) = 把 a₁..a_i 与 {b_j : j ∈ U} 恰好匹配的方案数。看 a_i 的配偶：

M(i,U) = Σj ∈ U, aibj ∈ E M(i−1, U∖{j})，　M(0, ∅) = 1

情况互不重叠（a_i 恰有一个配偶）⇒ 计数相加不会重复（计数 DP 要额外检查不重复）。直接做 O(n²2ⁿ)。

练习答案：非零状态必有 i = |U| ⇒ 去掉冗余参数，F(U) = Σj∈U, a|U|bj∈E F(U∖{j})，2ⁿ 个状态 × n ⇒ O(n2ⁿ) 次加法、O(2ⁿ) 空间（答案可达 n!，有 Θ(n log n) 位）。

例

边：a₁–b₁,b₂,b₃；a₂–b₁,b₃；a₃–b₁,b₂（无 a₃b₃）。M(3,{1,2,3}) = M(2,{2,3}) + M(2,{1,3}) = 1 + 2 = 3。

着色剩余顶点最少颜色

课件练习：路径上的最大权独立集（含答案）

D(i) = 只用前 i 个点的最大权。第 i 个点要么不选（D(i−1)），要么选——此时 i−1 不能选，剩下恰好是“到 i−2 为止的前缀”：

D(0) = 0,　D(1) = w1,　D(i) = max{ D(i−1), wi + D(i−2) }

例：权 3, 2, 5, 10, 7 ⇒ D = 0, 3, 3, 8, 13, 15；回溯：D(5)=D(3)+7 选 5，D(3)=D(1)+5 选 3，选 1 ⇒ {1,3,5}，权 15。O(n)。只留两个值可以算出最优值，但要输出选了哪些点，需要保留表（或每步的选择）——两个值不够回溯。

谜题：桌面上的硬币

25 枚等大硬币（半径 r）放满桌面使得再放不下一枚。则桌面每一点到某个圆心的距离 < 2r（否则可以以该点为圆心再放一枚）⇒ 半径放大到 2r 的 25 个圆盖住桌面。整体缩小一半：25 枚半径 r 的硬币盖住一张长宽各为一半的桌子；原桌面可分成 4 张这样的小桌 ⇒ 100 枚硬币可以盖住整张桌子。

8选读：字符串匹配

在文本 A = a1…an 中找模式 B = b1…bm 的所有连续出现（与 LCS 不同，不允许间隔）。朴素：每个起点比 m 个字符，最坏 O(nm)。

8.1 Rabin–Karp：滚动哈希

  • 多项式哈希：H(b1…bm) = (Σ bjdm−j) mod p。例：d=10、p=13，H(123) = 123 mod 13 = 6。首个哈希用 Horner：h ← (dh + bj) mod p。
  • 滚动更新：预算 r = dm−1 mod p，Hs+1 = (d(Hs − asr) + as+m) mod p。123→234：r=9，(10(6−9)+4) mod 13 = 0（= 234 mod 13 ✓）。
  • 哈希相等只是候选：H(123) = 6 = H(136)。必须逐字符验证。固定的大素数本身不带概率保证。
  • 代价：扫描 O(n+m) 次算术；z 个哈希碰撞窗口验证 O(zm)；最坏 O(nm)。实现注意溢出和负余数。

8.2 KMP：保留仍然有用的部分匹配

失败函数（前缀函数）

π(k) = 模式前缀 Bk 的最长真前缀、同时也是其后缀的长度（0 ≤ π(k) < k）。例 B = xyxyxzx：

k1234567
bkxyxyxzx
π(k)0012301

π(5) = 3：xyxyx 的前缀 xyx = 后缀 xyx。失败链 5 → 3 → 1 → 0 按从长到短列出所有可能保留的长度（更短的前后缀一定也是最长那个的前后缀）。

// 构造 π（π(1) = 0）
for k = 2..m:
    q = π(k-1)
    while q > 0 and b[q+1] != b[k]: q = π(q)
    if b[q+1] == b[k]: q = q + 1
    π(k) = q
// 扫描文本
q = 0
for i = 1..n:
    while q > 0 and b[q+1] != a[i]: q = π(q)
    if b[q+1] == a[i]: q = q + 1
    if q == m: report match at i-m+1; q = π(m)   // 允许重叠出现
完整扫描：A = xyxyxyxzx，B = xyxyxzx

每步之后的匹配长度：1, 2, 3, 4, 5, 4, 5, 6, 7。i = 6 时长度 5 遇到 y 而模式期待 z：退到 π(5) = 3，再用同一个 y 扩展到 4。i = 9 长度到 7 ⇒ 在位置 9−7+1 = 3 匹配，然后退到 π(7) = 1 以便发现重叠的出现。构造 π 时 k = 6：q=π(5)=3 期待 y 读到 z → q=π(3)=1 仍期待 y → q=π(1)=0，x≠z ⇒ π(6)=0。

正确性与线性时间

失败时更短的部分匹配必须以同一文本位置结束（是 Bq 的后缀），又必须是模式前缀 ⇒ 正是失败链上的长度，从长到短检查，不会漏掉匹配。势能论证：文本指针只前进 n 次，每次 q 至多加 1；q 从不为负，所以所有回退之和 ≤ 所有增加之和 ⇒ 扫描 O(n)，构造 π 同理 O(m)，总 O(n+m)。

有限自动机视角：状态 q ∈ {0..m}，转移 δ(q, c) 把“回退 + 扩展”预先算好（如 δ(5, y) = 4）。
